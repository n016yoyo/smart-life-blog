크롬 사이드바에서 클로드가 탭을 대신 정리합니다

크롬 사이드 패널이 Claude Cowork 세션이 됐습니다. 청구서 탭 열 개를 띄워두고 한 줄만 시키면, 클로드가 탭을 하나씩 열어 읽고 금액을 대조해 쓰던 시트 양식에 채웁니다. 되는 요금제와 실제로 막히는 지점까지 정리했습니다.

WHAT CHANGED

사이드 패널을 열면 그게 Cowork 세션입니다

전에는 크롬 확장이 "지금 이 페이지"를 도와주는 도구였습니다. 이제는 사이드 패널을 여는 순간 Cowork 세션이 시작됩니다. 달라지는 건 세 가지입니다.

대화가 기록에 남는다 스킬·커넥터가 브라우저에서 그대로 동작 데스크톱·웹·모바일에서 이어받기

탭에서 시작한 일을 데스크톱 앱에서 이어받아 내 컴퓨터 파일을 붙이거나, 지난달 자료를 불러와 "뭐가 달라졌냐"고 물을 수 있습니다.

직접 연동이 있는 서비스는 그걸 쓰는 게 낫습니다. 크롬 확장이 채우는 자리는 사내 대시보드·오래된 시스템·거래처 포털처럼 연동이 없는 웹입니다.

SETUP

설치는 주소 하나

  1. claude.com/chrome 에서 확장을 설치합니다.
  2. 크롬 오른쪽 위, 주소창 옆에 생긴 클로드 아이콘을 누릅니다.
  3. 사이드 패널이 열리면 그게 Cowork 세션입니다. 따로 켤 설정은 없습니다.
확장은 페이지를 보고 조작합니다. 링크를 누르고, 글자를 입력하고, 페이지를 넘기고, 양식을 채웁니다. 그래서 아래 함정 절을 꼭 읽으세요.
PROMPT

한 줄로 시키기

정리하고 싶은 페이지들을 탭으로 미리 열어두는 것이 준비의 전부입니다. 붙여넣기도 업로드도 필요 없습니다. 그다음 사이드 패널에 이렇게 씁니다.

왜 "지난달과 같은 열·같은 순서"를 넣나요. 이 한 마디가 없으면 매달 형식이 달라져서, 결국 사람이 다시 정리하게 됩니다. 쓰던 양식을 그대로 이어받게 하는 게 핵심입니다.
RESULT

클로드가 하는 일은 셋입니다

  1. 열린 탭을 전부 읽습니다. 탭을 하나씩 열어 청구서를 확인합니다.
  2. 금액을 하나하나 대조합니다. 원본 청구서와 숫자를 맞춥니다.
  3. 쓰던 양식에 채웁니다. 지난달 로그와 같은 열, 같은 벤더 순서로 넣습니다.

그 과정에서 사람이 놓치기 쉬운 것을 따로 짚어줍니다. 공식 데모에서 실제로 나온 항목입니다.

TRAPS

실제로 막히는 지점 네 가지

⚠ 내 컴퓨터 파일은 브라우저가 못 만집니다

확장은 웹 페이지만 봅니다. 내 컴퓨터의 엑셀 파일을 붙이거나 다른 프로그램과 주고받으려면 데스크톱 앱이 필요합니다. 탭에서 시작해 데스크톱에서 이어받는 식으로 씁니다.

⚠ 프롬프트 인젝션 위험이 있습니다

클로드가 읽는 웹 페이지 안에 "이렇게 해라"는 지시문을 심어두는 공격입니다. 앤트로픽도 이 위험이 남아 있다고 밝혔고, 그래서 결과가 큰 동작에는 추가 확인을 받게 돼 있습니다. 확인창이 뜨면 그냥 넘기지 말고 읽으세요.

⚠ 크롬이 아니면 안 됩니다

엣지·브레이브 같은 다른 크로미움 브라우저와 모바일에서는 동작하지 않습니다. 회사 PC가 크롬이 아니면 이 방법은 못 씁니다.

⚠ 탭을 안 열어두면 아무 일도 안 일어납니다

"이 탭들로"가 명령의 핵심입니다. 정리하고 싶은 페이지를 미리 다 열어둔 상태에서 시켜야 합니다. 로그인이 필요한 포털이면 로그인까지 해둔 탭이어야 합니다.
