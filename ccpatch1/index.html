+$1.31 65분 쉬고 한마디+$0.03 1분 뒤 같은 말54분 9초 자동 압축

제가 해 본 것

공개 소설(구텐베르크 《오만과 편견》)을 통째로 읽힌 시연 대화를 만들고, 마지막 응답 뒤 65분을 쉬었다가 「고마워」 한마디를 보냈어요. 상태 줄 비용 표시가 $1.44 에서 $2.75 로 1.31달러 올랐어요. 55초 뒤 같은 말을 한 번 더 보내니 $2.75 → $2.78, 3센트였어요.

차이는 프롬프트 캐시예요. 쉬는 동안 1시간 캐시가 식어서 첫 한마디에 대화 전체(이번엔 327,241 토큰)를 다시 썼고, 바로 다음 말은 캐시에서 읽었어요(354,567 토큰을 읽기만 함).

※ 2026-10-25, 제 시연 한 번의 값이에요. 상태 줄의 달러는 사용량을 API 단가로 환산한 표시예요. 구독 요금제는 돈이 따로 나가지 않고 5시간·주간 한도에서 깎여요.

1

한 시간 넘게 쉬었으면 새 대화로

v2.1.304 부터 Pro·Max 요금제에서 쉰 대화를 이어 가면 5시간 한도를 꽤 쓸 때 경고가 떠요. 「그래도 이어 가기」나 「새 대화」를 고르는데, 새 대화에서 이전 대화를 말하면 클로드가 찾아본다고 해요. (제 시연에서는 이 경고가 뜨지 않았어요.)

2

쉬는 동안 자동 압축 (v2.1.299)

20만 토큰이 넘는 대화를 약 54분 그대로 두면 캐시가 식기 전에 알아서 압축해 둬요. 제 시연은 54분 9초에 압축됐고 109,437 → 10,316 토큰이 됐어요(기준을 2만 토큰으로 낮춰서 잰 값).

3

설정에서 켜고 끄기 (v2.1.302)

클로드 코드에서 /config 를 열고 검색 칸에 idle 을 치면 Idle compaction 줄이 나와요. 여기서 끄거나 다시 켜요.

settings.json 으로 끄기 (공식 문구 그대로)
{
  "idleCompaction": false
}
압축 기준(기본 20만 토큰) 바꾸기 , 값은 예시
export CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS=100000

이 방법의 한계예요

시연 한 번씩의 값이에요. 비용은 대화 크기와 모델에 따라 달라요. 자동 압축은 기본으로 20만 토큰이 넘는 대화에만 걸려요(제 시연은 공식 환경 변수로 기준을 2만으로 낮췄어요). 압축하면 대화가 요약으로 줄어서, 아주 자세한 앞부분이 필요하면 끄는 게 나을 수도 있어요. 환경 변수와 settings.json 끄기는 v2.1.290 이후 버전에서 돼요.
