TRAPS

실전 함정 여덟 가지

제가 직접 밟은 것들입니다. 공식 플러그인을 써도 밟는 것들만 여기 뒀습니다. API 로 직접 붙일 때만 나오는 함정은 아래 부록으로 내렸습니다.

⚠ 1 · "폴더에 저장해줘"라고 하면 폴더로 안 갑니다

저장 위치를 정해주고 싶어서 langs 폴더를 만들어두고 거기 저장하라고 시켰습니다. 여덟 개 다 성공했다고 나왔는데 폴더는 비어 있었습니다. 상위 폴더에 langs.ar langs.he 처럼 확장자 없는 파일 여덟 개가 떨어져 있었습니다. 확장자가 없으니 더블클릭해도 안 열립니다.

플러그인 코드를 보니 의도된 동작이었습니다. 입력 파일이 하나면 저장 경로를 "폴더"가 아니라 "파일 이름"으로 봅니다. 폴더로 취급되는 건 입력이 여러 개일 때뿐입니다.

그냥 저장 위치를 말하지 마세요. 아무 말 안 하면 원본 파일 옆에 언어별로 알아서 떨어집니다. 굳이 옮기고 싶으면 다 받은 다음에 "받은 것들 langs 폴더로 옮겨줘"라고 따로 시키세요.

⚠ 2 · 브라우저가 없는 환경이면 키 등록에서 멈춥니다

설치하면 첫 실행 때 브라우저가 열려서 로그인 한 번으로 키가 잡힙니다. 자기 컴퓨터에서는 이게 제일 편합니다.

그런데 저는 서버에서 돌리느라 브라우저가 없었습니다. 화면에 주소만 뜬 채로 오 분을 기다리다 끝났습니다. 그 주소는 같은 컴퓨터의 브라우저로 열어야 해서, 폰으로 열어봐야 소용이 없습니다.

이때는 파일로 넣는 길이 따로 있습니다. 클로드에게 이렇게 말하면 됩니다.

브라우저가 안 열릴 때

키는 채팅창에 붙여넣지 마세요. 파일로 주면 플러그인이 읽어서 암호화해 저장하고 원본 파일은 지웁니다.

⚠ 3 · 개발자 문서의 최소 길이는 옛날 값입니다

API 문서에는 400 F4009: Video duration too short (min 5s) 라고 적혀 있습니다. 저도 그걸 믿고 처음부터 오점사 초로 올렸습니다.

직접 시험해보니 1.224초짜리가 그냥 통과했습니다. Perso 측 확인도 1초 이상이면 된다는 쪽입니다. 문서가 아직 안 고쳐진 것 같으니, 짧은 클립으로 시험하실 때 참고하세요.

⚠ 4 · 무료 플랜은 완성본을 못 받습니다 (문서에 없음)

"받을 수 있다"고 답하는 응답까지 와놓고, 실제로 받으려 하면 FREE_USER_CAN_NOT_DOWNLOAD 입니다. 존재하지 않는 항목을 요청해도 같은 에러가 나와서 "내가 값을 잘못 넣었나" 하고 한참 헤맵니다. 우회로는 대본 API가 주는 문장별 음성을 받아 이어 붙이는 것입니다. 그건 안 막혀 있습니다. 유료로 올리면 제한이 풀립니다.

동시 처리 개수도 다릅니다. 무료는 한 개, 유료는 세 개입니다. 제가 여덟 개 언어를 돌렸을 때 화면에 Queue 3/3 이 계속 찍히면서 세 개씩 소화했습니다. 무료면 한 줄로 서니 훨씬 오래 걸립니다.

⚠ 5 · 잘못 걸었을 때 취소가 안 됩니다

대기열에 있는 동안만 취소됩니다. 그런데 대기열이 비어 있으면 요청하자마자 바로 처리가 시작돼서, 만들자마자 취소해도 거절당하는 일이 흔합니다. "잘못 걸면 취소하면 되지"라고 생각하고 설계하지 마세요. 할당량은 이미 나갑니다. 언어 목록을 확정한 다음에 돌리세요.

⚠ 6 · 사람 이름 같은 고유명사는 회차마다 표기가 달라질 수 있습니다

문장 번역 자체는 잘 됩니다. 그런데 이름 같은 고유명사를 그 나라 글자로 음차할지, 라틴 문자 그대로 둘지가 회차마다 갈립니다. 저는 같은 문장을 조지아어로 두 번 돌렸는데 한 번은 "Claude" 가 კლოდიმ 로 바뀌어 왔고, 한 번은 Claude-მა 로 라틴 그대로 왔습니다. 아르메니아어에서도 같은 일이 있었습니다.

번역 품질 문제가 아니라 고유명사 표기 문제입니다. 이름이 화면에 크게 나가는 영상이라면 결과를 눈으로 확인하고 쓰세요. 클로드에게 "번역 결과 원문도 파일로 남겨줘"라고 시키면 나중에 대조할 수 있습니다.

⚠ 7 · 한글·태국어·아랍어 글자가 네모(□)로 나옵니다

받아온 번역문을 화면이나 이미지에 넣으면 대부분 두부처럼 네모로 깨집니다. 그 문자를 담은 폰트가 없어서입니다. 언어마다 맞는 Noto 폰트를 따로 설치해야 합니다. 저는 일곱 종을 깔았습니다. 이것도 클로드에게 "이 언어 글자가 네모로 나온다"고 말하면 알아서 깝니다.

⚠ 8 · 받아온 음성을 영상에 얹을 때 국기 이미지를 조심하세요

나라별 화면을 만들면서 국기에 테두리와 그림자를 일괄로 씌우면, 네팔에서 깨집니다. 네팔 국기는 세계에서 유일하게 사각형이 아니라(삼각기 두 개) 투명한 부분에 흰 상자가 그대로 드러납니다. 네팔만 실루엣을 따라가는 그림자(drop-shadow)를 쓰면 됩니다.

     (3) 올린 주소를 perso 에 통보해서 mediaSeq 를 받는다
   ★403 이 나면 임시 주소가 만료된 거다. (1)부터 다시.
2) 목표 언어들을 번역 요청한다.
   ★언어마다 지원하는 음성 모델이 다르다. 언어 목록을 먼저 조회해서
     그 언어가 실제로 지원하는 모델만 지정할 것. 아무거나 넣으면 400 이 난다.
   ★같은 언어 코드가 목록에 여러 번 나온다(영어 US·UK 처럼).
     코드만 보고 집지 말고 지역 표시까지 확인해라. 지원 모델이 서로 다르다.
   ★요청 하나가 프로젝트를 여러 개 만든다. 응답이 배열로 온다.
     하나만 보고 끝내면 나머지 언어를 통째로 놓친다. 전부 각각 확인해라.
   ★동시에 3개까지만 돌린다(무료는 1개). 그 이상은 큐에서 밀린다.
3) 진행률을 5초 간격으로 확인한다.
   ★완료 판정은 progressReason 이 "Completed" 인 것으로만 한다.
     진행률 100%만 보고 받으러 가면 아직 빈손이다.
4) 결과를 언어별 mp3 로 저장한다.
   ★무료 플랜이면 완성본 다운로드가 막힌다(FREE_USER_CAN_NOT_DOWNLOAD).
     그때는 대본 API 가 주는 문장별 음성(audioUrl)을 받아 이어 붙여라.
     이 경로는 안 막혀 있다.
5) 시작·끝 할당량을 찍어서 이번 작업에 얼마 나갔는지 보여줘.

응답 처리
- 어떤 응답은 result 로 한 겹 감싸져 오고 어떤 건 안 감싸져 온다.
  값이 undefined 로 나오면 그것부터 의심해라.
- 에러가 나면 본문의 detailCode 를 먼저 출력해라. 원인이 거기 있다.

출력
- 진행 상황을 단계별로 화면에 출력해줘.
- 번역된 원문도 파일로 남겨줘. 나중에 대조할 수 있게.
- 다 만들고 나면 어떻게 실행하는지 한 줄로 알려줘.

API 로 직접 붙일 때만 나오는 함정

아래 넷은 플러그인이 이미 처리해줍니다. 직접 붙일 때만 밟습니다.

⚠ 업로드가 3단입니다

더빙 요청에 파일을 바로 못 붙입니다. 임시 주소를 받고, 그 주소로 직접 올리고, 올렸다고 통보해서 번호를 받는 순서입니다. 임시 주소는 삼십 분만 삽니다. 403 이 나면 만료된 겁니다. 그리고 그 주소의 호스트를 코드에 박아넣지 마세요. 바뀝니다.

⚠ 언어와 음성 모델 짝이 안 맞으면 거절당합니다

좋아 보이는 모델을 전 언어에 일괄로 지정했더니 일부 언어에서 400 이 났습니다. 언어마다 지원 모델이 다릅니다. 언어 목록을 먼저 받아서 그 언어가 실제로 지원하는 것만 고르게 해야 합니다. 같은 언어 코드가 목록에 여러 번 나오기도 합니다(영어 US·UK 처럼). 지역 표시까지 보고 골라야 합니다.

⚠ 완료 직후 몇 초는 아직 "안 됐다"고 나옵니다

진행률이 100%가 됐다고 바로 받으러 가면 빈손입니다. 완료 판정은 progressReason 이 "Completed" 인 것으로만 하고, 그 뒤에도 몇 초 여유를 두게 시키세요.

⚠ 응답이 한 겹 감싸져 오는 게 있고 아닌 게 있습니다

어떤 응답은 { result: { ... } } 로 감싸져 오고 어떤 건 그냥 옵니다. 문서 예시는 안 감싸진 모양인데 실제로는 섞여 있습니다. 값이 자꾸 비어 보이면(undefined) 이걸 먼저 의심하세요. 저는 "받을 게 하나도 없다"는 잘못된 결론까지 갔다가 되돌아왔습니다.
