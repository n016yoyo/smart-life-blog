WHAT

이게 뭔데?

인스타그램은 릴스를 자동으로 번역해 더빙까지 해줍니다. 공짜고, 설정에서 켜기만 하면 됩니다. 좋은 기능인데 도착 언어가 정해져 있습니다.

제 계정 설정 화면을 직접 세어보니 정확히 열네 개였습니다. 켜져 있는 게 아홉, 꺼져 있는 게 다섯.

독일어스페인어영어이탈리아어일본어포르투갈어프랑스어힌디어한국어마라티어뱅골어칸나다어타밀어텔루구어

여기 없는 언어로는 아무리 해도 안 나갑니다. 아랍어도, 러시아어도, 히브리어도 없습니다.

열네
인스타 자동번역 도착어
일흔네
perso.ai 도착어

perso.ai 의 언어 목록을 API로 받아 직접 세어보니 자동 감지를 뺀 고유 코드가 일흔네 개였습니다. 인스타의 열네 개는 전부 그 안에 있으니, 차집합이 예순 개입니다.

이 가이드가 만드는 것 , 내 목소리가 담긴 오디오를 올리면, Claude Code가 perso API를 대신 불러 여러 언어로 한 번에 더빙본을 받아옵니다. 번역만 하는 게 아니라 음성을 새로 굽는 단계가 따로 돕니다.
HONEST

먼저, 정직하게 짚고 갑니다

✓ 번역·음성 생성·내려받기 자동 ✓ 여러 언어 동시 처리 △ Free 플랜은 완성본 다운로드 막힘 △ 목소리 동일성은 수치로 보장 못 함

목소리가 "똑같이" 복제된다고는 말하지 않겠습니다. 제가 원본과 더빙본의 스펙트럼 중심(목소리 밝기를 대표하는 값)을 직접 재봤는데, 원본 1651Hz 대 더빙 1718~2149Hz로 언어마다 갈렸습니다. 같다고 주장할 만한 수치가 안 나왔습니다.

확실하게 말할 수 있는 건 이겁니다. 실행 화면에 Transcribing → Translating → Generating Voice 단계가 차례로 찍힙니다. 번역문만 뽑는 게 아니라 음성을 새로 굽는 공정이 실제로 돕니다.

Free 플랜이면 완성 더빙 영상은 못 받습니다. 공식 문서엔 이 얘기가 없고, "받을 수 있다"고 답하는 API 응답까지 옵니다. 그런데 실제로 받으려 하면 FREE_USER_CAN_NOT_DOWNLOAD 로 거절합니다. 우회로는 있습니다 , 대본 API가 주는 문장별 음성 파일은 안 막혀 있어서, 그걸 받아 이어 붙이면 됩니다.

Claude Code이 도구를 만들어줄 주인공. 설치만 하면 됩니다. 설치 가이드
perso.ai 계정번역·더빙을 실제로 하는 곳. 로그인 후 개발자 도구에서 인증 토큰을 복사해 둡니다.

코딩 지식필요 없습니다. 아래 요청 파일을 그대로 쓰면 됩니다.
STEP 1

요청 파일 한 장을 만듭니다

명령을 채팅에 길게 치는 대신 파일 한 장으로 만들어 두면 나중에 그대로 다시 돌릴 수 있고, 무엇을 시켰는지 기록으로 남습니다.

ask.txt 로 저장
내 목소리 mp3 를 perso.ai 로 아랍어·히브리어·아르메니아어·조지아어·네팔어·말라얄람어·우르두어·러시아어 여덟 개로 더빙해줘. 목소리는 원본 그대로 복제하고, 나라별 mp3 로 내려받아 _work/langs 에 저장해.

언어는 원하는 대로 바꾸세요. perso 가 지원하는 일흔네 개 중 아무거나 됩니다.

그리고 Claude Code 에 이렇게 시킵니다.

Claude Code 에 그대로 붙여넣기
ask.txt 에 적은 대로 perso.ai 더빙 자동화를 만들어줘.

동작 순서
1) 오디오를 업로드한다 (perso 업로드는 3단이다:
   업로드 URL 요청 → 실제 전송 → 완료 통보. 한 번에 안 된다)
2) 목표 언어들을 한꺼번에 번역 요청한다.
   ★언어마다 지원하는 TTS 모델이 다르다. 지원 목록을 먼저 조회해서
     그 언어가 실제로 지원하는 모델만 지정할 것. 아무거나 넣으면 400 이 난다.
   ★동시에 세 개까지만 돌린다. 그 이상은 큐에서 밀린다.
3) 진행률을 5초 간격으로 확인한다.
   완료 판정은 progressReason === "Completed" 로만 한다.
4) 문장별 음성(audioUrl)을 받아 언어별 mp3 로 저장한다.
   ★Free 플랜이면 완성본 download 가 막히므로 이 경로를 쓴다.
5) 시작·끝 할당량을 찍어서 이번 작업에 얼마가 나갔는지 보여줘.

진행 상황을 단계별로 화면에 출력해줘. 번역 결과 원문도 파일로 남겨줘.
STEP 2

그다음부턴 두 줄

Claude 가 코드를 다 짜면, 이후엔 이게 전부입니다.

실행

TRAPS

실전 함정 일곱 가지

제가 직접 밟은 것들입니다. 미리 알면 안 밟습니다.

⚠ 1 · 오디오가 오 초보다 짧으면 안 올라갑니다

짧은 문장 하나만 테스트하려다 계속 거절당했습니다. 소스는 오 초를 넘겨야 합니다. 테스트용이라도 문장 두세 개는 넣으세요.

⚠ 2 · 언어와 TTS 모델 짝이 안 맞으면 거절당합니다

좋아 보이는 모델을 전 언어에 일괄로 지정했더니 일부 언어에서 400 이 났습니다. 언어마다 지원 모델이 다릅니다. 언어 목록을 먼저 받아서 그 언어가 실제로 지원하는 것만 고르게 해야 합니다.

⚠ 3 · Free 플랜은 완성본을 못 받습니다 (문서에 없음)

"받을 수 있다"고 답하는 응답까지 와놓고, 실제로 받으려 하면 FREE_USER_CAN_NOT_DOWNLOAD 입니다. 존재하지 않는 항목을 요청해도 같은 에러가 나와서 "내가 값을 잘못 넣었나" 하고 한참 헤맵니다. 에러 본문의 detailCode 를 먼저 보세요. 우회로는 문장별 음성 파일을 받아 이어 붙이는 것입니다.

⚠ 4 · 완료 직후 몇 초는 아직 "안 됐다"고 나옵니다

진행률이 100%가 됐다고 바로 받으러 가면 빈손입니다. 완료 판정은 progressReason === "Completed" 로만 하고, 그 뒤에도 몇 초 여유를 두게 시키세요.

⚠ 5 · 한글·태국어·아랍어 글자가 네모(□)로 나옵니다

받아온 번역문을 화면이나 이미지에 넣으면 대부분 두부처럼 네모로 깨집니다. 그 문자를 담은 폰트가 없어서입니다. 언어마다 맞는 Noto 폰트를 따로 설치해야 합니다. 저는 일곱 종을 깔았습니다.

⚠ 6 · 언어에 따라 이름을 원어로 안 바꿔줍니다

"Claude"를 그 나라 글자로 써주길 기대했는데, 언어에 따라 라틴 문자 그대로 두고 옵니다. 같은 언어인데도 회차마다 다르게 오기도 합니다. 결과를 눈으로 확인하고 쓰세요. 저는 조지아어에서 이걸 겪었습니다.

⚠ 7 · 받아온 음성을 이어 붙일 때 소리가 사라집니다

perso 가 주는 음성과 내가 만든 음성의 샘플레이트가 다르면(예: 44.1kHz 대 48kHz) 그냥 이어 붙였을 때 일부 구간이 조용히 잘려나갑니다. 에러도 안 납니다. 붙이기 전에 샘플레이트를 하나로 맞추게 시키세요.
