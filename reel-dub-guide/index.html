WHAT

이게 뭔데?

인스타그램은 릴스를 자동으로 번역해 더빙까지 해줍니다. 공짜고, 설정에서 켜기만 하면 됩니다. 좋은 기능인데 도착 언어가 정해져 있습니다.

제 계정 설정 화면을 직접 세어보니 정확히 열네 개였습니다. 켜져 있는 게 아홉, 꺼져 있는 게 다섯.

독일어스페인어영어이탈리아어일본어포르투갈어프랑스어힌디어한국어마라티어뱅골어칸나다어타밀어텔루구어

여기 없는 언어로는 아무리 해도 안 나갑니다. 아랍어도, 러시아어도, 히브리어도 없습니다.

열네
인스타 자동번역 도착어
일흔네
perso.ai 도착어

perso.ai 의 언어 목록을 API로 받아 직접 세어보니 자동 감지를 뺀 고유 코드가 일흔네 개였습니다. 인스타의 열네 개는 전부 그 안에 있으니, 차집합이 예순 개입니다.

이 가이드가 만드는 것 , 내 목소리가 담긴 오디오를 올리면, Claude Code가 perso API를 대신 불러 여러 언어로 한 번에 더빙본을 받아옵니다. 번역만 하는 게 아니라 음성을 새로 굽는 단계가 따로 돕니다.
컴퓨터에 아무것도 없어도 됩니다. 이 가이드는 Claude Code만 깔린 상태를 기준으로 씁니다. 파이썬도, Node도, ffmpeg도 미리 깔 필요 없습니다. 아래 프롬프트를 붙여넣으면 필요한 걸 클로드가 알아서 확인하고 설치합니다.
HONEST

먼저, 정직하게 짚고 갑니다

✓ 번역·음성 생성·내려받기 자동 ✓ 여러 언어 동시 처리 △ 무료 플랜은 완성본 다운로드 막힘 △ 목소리 동일성은 수치로 보장 못 함

목소리가 "똑같이" 복제된다고는 말하지 않겠습니다. 제가 원본과 더빙본의 스펙트럼 중심(목소리 밝기를 대표하는 값)을 직접 재봤는데, 원본 1651Hz 대 더빙 1718~2149Hz로 언어마다 갈렸습니다. 같다고 주장할 만한 수치가 안 나왔습니다.

확실하게 말할 수 있는 건 이겁니다. 실행 화면에 Transcribing → Translating → Generating Voice 단계가 차례로 찍힙니다. 번역문만 뽑는 게 아니라 음성을 새로 굽는 공정이 실제로 돕니다.

돈 얘기도 하겠습니다. perso.ai 는 미디어 일 초에 할당량 일이 나가고, 목표 언어 수만큼 곱해집니다. 삼십 초 릴스를 세 개 언어로 하면 구십입니다. 무료 플랜은 번역·음성 생성까지는 되는데 완성본 내려받기가 막힙니다(우회로는 함정 3번). 유료로 올리면 풀립니다.
PREP

준비물은 두 개뿐

준비물설명
Claude Code이 도구를 만들어줄 주인공. 이것만 있으면 됩니다. 설치 가이드
perso.ai API 키번역·더빙을 실제로 하는 곳. 아래 1단계에서 받습니다.
Node·ffmpeg미리 깔 필요 없습니다. 2단계에서 클로드가 확인하고 없으면 설치합니다.
코딩 지식필요 없습니다. 아래 상자를 복사해서 붙여넣는 게 전부입니다.

더빙할 오디오는 오 초를 넘겨야 합니다(함정 1번). 없으면 폰 녹음기로 두세 문장 읽어 만드세요.

STEP 1

API 키 받기 , 사람이 하는 유일한 단계

  1. perso.ai 에 가입하고 로그인합니다.
  2. 계정 설정에서 API 키를 발급합니다. pk_live_ 로 시작하는 긴 문자열입니다.
  3. 복사해 둡니다. 다음 단계에서 클로드에게 한 번만 알려주면 됩니다.
키는 비밀번호입니다. 남에게 보여주는 화면·영상·깃허브에 절대 올라가면 안 됩니다. 아래 프롬프트는 키를 .env 파일에 넣고 .gitignore 에 등록까지 시킵니다. 그 두 줄을 빼지 마세요.
STEP 2

클로드에게 환경을 맡깁니다

폴더 하나를 새로 만들고 그 안에서 claude 를 켠 다음, 아래를 그대로 붙여넣습니다. 무엇이 깔려 있는지 몰라도 됩니다. 클로드가 확인하고 없는 것만 깝니다.

Claude Code 에 그대로 붙여넣기
perso.ai 더빙 자동화를 만들 거야. 먼저 이 컴퓨터 환경부터 준비해줘.

1) 지금 뭐가 깔려 있는지 확인해줘 (node, npm, ffmpeg, ffprobe).
   버전까지 찍어줘.
2) 없는 게 있으면 이 컴퓨터 운영체제에 맞는 방법으로 설치해줘.
   관리자 권한이 필요하면 나한테 명령어를 알려주고 기다려줘.
   내가 직접 실행할게.
3) 설치가 끝나면 다시 확인해서 전부 준비됐는지 보여줘.

그다음 이 폴더를 준비해줘.
- .env 파일을 만들고 PERSO_API_KEY= 한 줄만 넣어줘 (값은 내가 채울게)
- .gitignore 를 만들고 .env 와 받은 음성 폴더를 넣어줘
  ★키가 실수로 커밋되면 안 되니까 이건 꼭 해줘
- 준비가 끝나면 내가 뭘 하면 되는지 한 줄로 알려줘

클로드가 .env 를 만들어주면, 1단계에서 받은 키를 거기 넣습니다. 파일을 직접 열기 번거로우면 이렇게 시켜도 됩니다.

키 넣기 (키는 본인 것으로 교체)
.env 의 PERSO_API_KEY 값을 pk_live_여기에_내_키 로 채워줘.
넣고 나서 파일 내용은 화면에 출력하지 마. 키가 노출되면 안 되니까
"채웠다"고만 알려줘.
STEP 3

요청 파일 한 장 + 만들기

명령을 채팅에 길게 치는 대신 파일 한 장으로 만들어 두면 나중에 그대로 다시 돌릴 수 있고, 무엇을 시켰는지 기록으로 남습니다.

Claude Code 에 그대로 붙여넣기 (언어는 바꿔도 됨)
ask.txt 라는 파일을 만들고 아래 한 줄을 넣어줘.

내 목소리 mp3 를 perso.ai 로 아랍어·히브리어·아르메니아어·조지아어·네팔어·말라얄람어·우르두어·러시아어 여덟 개로 더빙해줘. 목소리는 원본 그대로 복제하고, 나라별 mp3 로 내려받아 langs 폴더에 저장해.

그리고 실제로 만들라고 시킵니다. 함정을 미리 알려주는 문장들이 들어 있습니다. 이게 없으면 대부분 여기서 막힙니다.

Claude Code 에 그대로 붙여넣기
ask.txt 에 적은 대로 perso.ai 더빙 자동화를 만들어줘.
공식 문서를 먼저 찾아 읽고, 아래 규칙을 지켜서 짜줘.

인증
- 헤더는 XP-API-KEY 다. Bearer 아니다.
- 키는 .env 의 PERSO_API_KEY 에서 읽어. 코드에 직접 쓰지 마.

동작 순서
1) 오디오를 업로드한다.
   ★업로드는 3단이다: 업로드 주소 요청 → 실제 전송 → 완료 통보.
     한 번에 안 된다.
   ★오디오가 5초보다 짧으면 거절당한다. 먼저 길이를 재고,
     짧으면 진행하지 말고 나한테 알려줘.
2) 목표 언어들을 번역 요청한다.
   ★언어마다 지원하는 음성 모델이 다르다. 언어 목록을 먼저 조회해서
     그 언어가 실제로 지원하는 모델만 지정할 것. 아무거나 넣으면 400 이 난다.
   ★동시에 3개까지만 돌린다. 그 이상은 큐에서 밀린다.
3) 진행률을 5초 간격으로 확인한다.
   ★완료 판정은 progressReason 이 "Completed" 인 것으로만 한다.
     진행률 100%만 보고 받으러 가면 아직 빈손이다.
4) 결과를 언어별 mp3 로 저장한다.
   ★무료 플랜이면 완성본 다운로드가 막힌다(FREE_USER_CAN_NOT_DOWNLOAD).
     그때는 대본 API 가 주는 문장별 음성(audioUrl)을 받아 이어 붙여라.
     이 경로는 안 막혀 있다.
   ★이어 붙일 때 파일들의 샘플레이트를 하나로 맞춰라.
     다르면 에러도 없이 일부 구간이 조용히 잘린다.
5) 시작·끝 할당량을 찍어서 이번 작업에 얼마 나갔는지 보여줘.

응답 처리
- 어떤 응답은 result 로 한 겹 감싸져 오고 어떤 건 안 감싸져 온다.
  값이 undefined 로 나오면 그것부터 의심해라.
- 에러가 나면 본문의 detailCode 를 먼저 출력해라. 원인이 거기 있다.

출력
- 진행 상황을 단계별로 화면에 출력해줘.
- 번역된 원문도 파일로 남겨줘. 나중에 대조할 수 있게.
- 다 만들고 나면 어떻게 실행하는지 한 줄로 알려줘.

TRAPS

실전 함정 아홉 가지

제가 직접 밟은 것들입니다. 위 프롬프트에는 이미 다 들어가 있으니 그대로 쓰면 안 밟습니다. 그래도 왜 그런지는 알아두세요.

⚠ 1 · 오디오가 오 초보다 짧으면 안 올라갑니다

짧은 문장 하나만 테스트하려다 계속 거절당했습니다. 소스는 오 초를 넘겨야 합니다. 테스트용이라도 문장 두세 개는 넣으세요.

⚠ 2 · 언어와 음성 모델 짝이 안 맞으면 거절당합니다

좋아 보이는 모델을 전 언어에 일괄로 지정했더니 일부 언어에서 400 이 났습니다. 언어마다 지원 모델이 다릅니다. 언어 목록을 먼저 받아서 그 언어가 실제로 지원하는 것만 고르게 해야 합니다.

⚠ 3 · 무료 플랜은 완성본을 못 받습니다 (문서에 없음)

"받을 수 있다"고 답하는 응답까지 와놓고, 실제로 받으려 하면 FREE_USER_CAN_NOT_DOWNLOAD 입니다. 존재하지 않는 항목을 요청해도 같은 에러가 나와서 "내가 값을 잘못 넣었나" 하고 한참 헤맵니다. 에러 본문의 detailCode 를 먼저 보세요. 우회로는 대본 API가 주는 문장별 음성을 받아 이어 붙이는 것입니다. 유료로 올리면 이 제한은 풀립니다.

⚠ 4 · 완료 직후 몇 초는 아직 "안 됐다"고 나옵니다

진행률이 100%가 됐다고 바로 받으러 가면 빈손입니다. 완료 판정은 progressReason 이 "Completed" 인 것으로만 하고, 그 뒤에도 몇 초 여유를 두게 시키세요.

⚠ 5 · 한글·태국어·아랍어 글자가 네모(□)로 나옵니다

받아온 번역문을 화면이나 이미지에 넣으면 대부분 두부처럼 네모로 깨집니다. 그 문자를 담은 폰트가 없어서입니다. 언어마다 맞는 Noto 폰트를 따로 설치해야 합니다. 저는 일곱 종을 깔았습니다. 이것도 클로드에게 "이 언어 글자가 네모로 나온다"고 말하면 알아서 깝니다.

⚠ 6 · 언어에 따라 이름을 원어로 안 바꿔줍니다

"Claude"를 그 나라 글자로 써주길 기대했는데, 언어에 따라 라틴 문자 그대로 두고 옵니다. 같은 언어인데도 회차마다 다르게 오기도 합니다. 결과를 눈으로 확인하고 쓰세요. 저는 조지아어에서 이걸 겪었습니다.

⚠ 7 · 받아온 음성을 이어 붙일 때 소리가 사라집니다

perso 가 주는 음성과 내가 만든 음성의 샘플레이트가 다르면(예: 44.1kHz 대 48kHz) 그냥 이어 붙였을 때 일부 구간이 조용히 잘려나갑니다. 에러도 안 납니다. 붙이기 전에 샘플레이트를 하나로 맞추게 시키세요.

⚠ 8 · 언어에 따라 회차마다 다른 답이 옵니다

같은 문장, 같은 언어인데 어제는 그 나라 글자로 오고 오늘은 라틴 문자로 옵니다. 저는 조지아어에서 겪었습니다. 결과를 파일로 남겨두고 눈으로 확인한 뒤 쓰세요. 화면에 내보낼 거라면 더더욱요. 클로드에게 "번역 결과 원문도 파일로 남겨줘"라고 시키면 나중에 대조할 수 있습니다.

⚠ 9 · 받아온 음성을 영상에 얹을 때 국기 이미지를 조심하세요

나라별 화면을 만들면서 국기에 테두리와 그림자를 일괄로 씌우면, 네팔에서 깨집니다. 네팔 국기는 세계에서 유일하게 사각형이 아니라(삼각기 두 개) 투명한 부분에 흰 상자가 그대로 드러납니다. 네팔만 실루엣을 따라가는 그림자(drop-shadow)를 쓰면 됩니다.
