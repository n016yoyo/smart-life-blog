8개 중 3개 사람이 볼 것4/4 같은 3개09:13 예약 실행

제가 해 본 것

이름 없는 예시 요청 8개를 파일로 두고, 정해진 시각에 클로드가 읽어 사람이 직접 답할 3개만 고르게 했어요. 예약해 둔 09시 13분에 아무도 입력하지 않았는데 혼자 돌았어요. 같은 요청 네 번, 고른 3개는 매번 같았고, 3일 묵은 거래처 문의는 네 번 다 3개에서 빠졌어요(짧게 답하라는 한 줄은 매번 붙었어요).

※ 2026-10-25, 하루 한 번 예약 실행만 시험했어요. 며칠 연속 실행은 시험하지 않았어요.

예시 요청 inbox.txt
1. 거래처 A: 견적서 보냈는데 확인했는지 물어봄 (3일 전)
2. 팀원 B: 다음 주 회의 자료 초안 검토 요청 (내일 오전까지)
3. 사이트 알림: 월 구독료 결제 예정 (자동 결제, 조치 필요 없음)
4. 거래처 C: 계약서 서명 요청 (이번 주 금요일 마감)
5. 뉴스레터: 이번 주 신제품 소식
6. 팀원 D: 점심 메뉴 투표
7. 은행: 이번 달 명세서 발급 안내
8. 거래처 E: 납품 일정 변경 가능한지 문의 (오늘 답 필요)
요청문 morning_prompt.txt (묵은 요청 한 줄은 아래 주의 참고)
inbox.txt 는 오늘 아침 받은 요청 8개야. 사람이 직접 보고 답해야 하는 것만 3개 골라서, 번호와 한 줄 이유로 알려줘. 나머지는 건드리지 않아도 된다고 한 줄로 말해줘. 아무것도 보내거나 바꾸지 말고 읽기만 해.
실행 스크립트 morning.sh
#!/bin/bash
# 정해진 시각에 claude -p 가 받은 요청을 읽고 사람이 봐야 할 3개를 brief.txt 에 적는다(읽기만, 보내거나 바꾸지 않음)
cd "$HOME/duet_demo"
claude -p "$(cat morning_prompt.txt)" --allowedTools "Read" --output-format text > brief.txt 2> brief_err.txt < /dev/null
date '+%m-%d %H:%M' > brief_done.txt
시간표 설정 (맥 LaunchAgent, 매일 08:00 예시)
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
<key>Label</key><string>com.demo.morningbrief</string>
<key>ProgramArguments</key><array><string>/Users/YOU/duet_demo/morning.sh</string></array>
<key>StartCalendarInterval</key><dict><key>Hour</key><integer>8</integer><key>Minute</key><integer>0</integer></dict>
</dict></plist>
1

폴더 만들기

~/duet_demo 에 inbox.txt · morning_prompt.txt · morning.sh 를 두고 chmod +x morning.sh.

2

시간표 걸기

설정 파일의 YOU 를 내 계정 이름으로 바꿔 ~/Library/LaunchAgents/ 에 넣고 launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.demo.morningbrief.plist.

3

끄기

launchctl bootout gui/$(id -u)/com.demo.morningbrief 후 설정 파일을 지워요.

이 방법의 한계예요

요청문에 「오래 묵은 요청도 챙겨 줘」 같은 줄이 없으면 마감이 가까운 것 위주로 골라요(제 네 번이 그랬어요). 결과는 brief.txt 파일로만 남겨요. 알림·메일 보내기는 넣지 않았어요. 실제 메일함을 읽게 하려면 그 연결은 직접 만드셔야 해요.

영상의 터미널 화면은 예약 실행이 남긴 실제 파일이에요. Duet 은 Anthropic 공식 영상에서 소개된 기능이고, 이 방법은 그것을 흉내 낸 것이지 같은 기능이 아니에요.
