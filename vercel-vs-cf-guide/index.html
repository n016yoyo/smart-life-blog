Vercel vs Cloudflare, 직접 올려본 비교표

둘 다 내 사이트를 세상에 올려주는 곳인데, 하나는 택배고 하나는 우체국입니다. 직접 배포해서 재봤습니다.

한 줄 결론 비유로 이해하기 비교표 배포 명령어 함정 어떤 걸 고를까
TL;DR

한 줄 결론

빨리 올리고 싶으면 Vercel, 돈 안 내고 전 세계에 깔고 싶으면 Cloudflare.

둘 다 "내가 만든 사이트를 인터넷에 올려주는 곳"입니다. GitHub에 코드 올리면 자동으로 사이트가 됩니다. 차이는 가격 구조와 글로벌 배포 범위입니다.

ANALOGY

비유로 이해하기

Vercel = 택배

빠르고 편합니다. 근데 무게(트래픽) 넘으면 추가요금이 나옵니다.

Cloudflare = 우체국

무게 제한 없이 전 세계로 공짜. 대신 처음 보내는 법을 한 번 익혀야 합니다.

DEPLOY

배포 명령어

Vercel

터미널
npm i -g vercel
vercel

물어보는 거 엔터 몇 번 치면 끝. 30초면 올라갑니다.

Cloudflare Pages

터미널
npm i -g wrangler
wrangler pages deploy ./dist --project-name my-site

처음 한 번 wrangler login으로 인증하면 그 뒤로는 명령어 한 줄입니다.

TRAPS

함정 4가지

1. Vercel 무료 대역폭 100GB는 생각보다 빨리 찹니다

이미지 많은 사이트 + SNS에서 트래픽 터지면 하루 만에 넘을 수 있습니다. 다음 달 청구서에 $20이 찍혀 있으면 이겁니다.

2. Cloudflare는 빌드가 500회/월입니다

git push 할 때마다 1회 소모. 하루에 열 번씩 고치면 한 달에 300회 씁니다. 넘으면 배포가 안 됩니다(과금은 아님).

3. Vercel의 서버리스 함수 실행 시간 제한

무료는 10초, Pro도 60초. AI API 호출처럼 오래 걸리는 건 타임아웃 납니다. Cloudflare Workers는 CPU 시간 10ms(무료)/50ms(유료)라 다른 제약.

4. 도메인 연결은 둘 다 무료인데 방법이 다릅니다

Vercel은 대시보드에서 클릭. Cloudflare는 네임서버를 Cloudflare로 옮겨야 합니다(다른 서비스와 충돌할 수 있음).

VERDICT

어떤 걸 고를까

상황추천

둘 다 무료로 시작합니다. 고민하지 말고 둘 다 올려보세요. 배포는 명령어 한 줄이고 삭제도 한 줄입니다. 확인 안 하고 Vercel에 트래픽 터지면 다음 달에 청구서 나오니까, 대시보드에서 Usage는 꼭 확인하세요.
