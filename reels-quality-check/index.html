⚠️ 진짜 문제는 화질이 아니라 배포

시청 시간이 두 무리 똑같습니다. 화질이 나빠서 사람이 나간 게 아니라, 인스타가 배포를 많이 하는 편과 고화질로 굽는 편을 같은 예측으로 고른다는 뜻이에요. Meta 가 공식 블로그에 적어둔 방식(페이스북 기준)이 이겁니다: 많이 볼 영상을 먼저 예측해서 그 영상에만 고급 인코딩(VP9)을 배정하고, 나머지는 기본 인코딩(H.264)만 받는다. 제 66편은 파일 규격이 전부 같은데 반반으로 갈렸으니, 기준은 파일이 아닙니다.

확인하는 코드 (영상에 나온 그 파일)

영상 속 ig_tier.js 그대로예요. 릴스 주소를 주면 🟢 고화질 판 있음 / 🔴 기본본만 을 찍어줍니다

클로드 코드에 이렇게 시키세요 (30초)

  1. 클로드 코드를 아무 폴더에서나 엽니다.
  2. 아래 프롬프트 복사를 눌러 채팅창에 붙여넣습니다. 코드까지 한 번에 들어가요. 확인할 릴스 주소는 프롬프트 맨 아래 줄에 붙입니다(여러 개 가능).
  3. 클로드가 yt-dlp 를 설치하고 ig_tier.js 를 만들어 돌린 뒤 표로 보여줍니다.
  4. 🟢 면 인스타가 밀어주는 편, 🔴 면 기본본만 나가는 편. 올린 다음 날 아침에 보세요. 그 뒤엔 안 바뀝니다.
프롬프트 + 코드 전체 복사
yt-dlp 가 없으면 설치하고(pip install yt-dlp 또는 GitHub 릴리스 바이너리), 아래 코드를 이 폴더에 ig_tier.js 로 저장한 뒤 `node ig_tier.js <릴스 주소>` 로 아래 릴스들의 인스타 서빙 화질 판을 확인해서 표로 보여줘. 코드는 수정하지 마. 🟢 는 인스타가 VP9 고화질 판을 만든 편, 🔴 는 H.264 720p 기본본만 있는 편이야.

릴스 주소:
https://www.instagram.com/reel/여기에_주소/

```js
#!/usr/bin/env node
// 인스타 릴스 화질 등급 확인 , 인스타 서버가 그 릴스를 어떤 화질로 서빙하는지 읽는다(쿠키·로그인 불필요, 공개 릴스).
// 쓰는 법: node ig_tier.js <릴스 주소> [<릴스 주소> ...]
// 필요: yt-dlp (https://github.com/yt-dlp/yt-dlp , 클로드코드에 yt-dlp 설치해 달라고 하면 된다)
// 판정: formats 에 vp09(VP9) 판이 있으면 🟢 고화질 판 있음 / avc1 720p 만 있으면 🔴 저화질 판만.
const { execFileSync } = require("child_process");
const urls = process.argv.slice(2);
if (!urls.length) { console.log("사용: node ig_tier.js <릴스 주소> ..."); process.exit(2); }
for (const url of urls) {
  let j;
  try { j = JSON.parse(execFileSync("yt-dlp", ["-j", url], { stdio: ["ignore", "pipe", "ignore"], maxBuffer: 1 << 26 }).toString()); }
  catch (e) { console.log(`${url}\n  ❌ 못 읽음(비공개이거나 yt-dlp 없음)`); continue; }
  const fm = (j.formats || []).filter(f => f.vcodec && f.vcodec !== "none" && f.height);
  const rows = fm.map(f => `  ${(f.vcodec || "").slice(0, 4).padEnd(5)} ${String(f.width + "x" + f.height).padEnd(10)} ${String(Math.round(f.tbr || 0) + "k").padStart(6)}`);
  const hasVp9 = fm.some(f => /^vp09/.test(f.vcodec)), top = Math.max(...fm.map(f => Math.min(f.width, f.height)));
  console.log(`${url.replace(/^https?:\/\/(www\.)?/, "")}`);
  console.log(rows.join("\n"));
  console.log(hasVp9 ? `  🟢 고화질 판 있음 (VP9 ${top}p)` : `  🔴 저화질 판만 (H.264 ${top}p)`);
}
```

알아둘 것

  • 공개 릴스만 읽힙니다. 비공개 계정·삭제된 편은 「못 읽음」.
  • 영상은 내려받지 않습니다. 인스타가 공개하는 포맷 목록만 읽어요(로그인·쿠키 불필요).
  • 판정 시점은 올린 다음 날 아침 기준입니다(13시간 뒤 실측). 그날 밤에 벌써 붙는지는 아직 못 쟀어요.
  • 4K·HEVC 같은 다른 파일 규격은 제가 잰 적이 없습니다. 제 66편은 전부 같은 규격이었고 반반으로 갈렸다는 게 근거예요.
  • 내 쪽에서 고화질 판을 강제로 받게 하는 방법은 없습니다. 이 코드는 「받았나」를 읽어주는 것이지 「받게 해주는」 것이 아니에요.
