한 줄 요약

클로드 코드에 새로 생긴 Projects(2026년 9월 17일 베타)에 제 블로그 가이드 78편 점검을 맡겼습니다. "나눠서 동시에 돌려줘" 한 줄을 보내자 코디네이터가 4묶음으로 나눠 스레드를 띄웠고, 제가 20:17:17 에 브라우저를 닫은 뒤에도 두 묶음이 더 끝나 PR 4개가 올라와 있었습니다.

PR(풀 리퀘스트)은 "이렇게 고쳤으니 확인하고 반영해 달라"는 요청 묶음입니다. 제가 병합하기 전까지 블로그에는 반영되지 않습니다.

켜자마자 바꿀 설정 두 개

Project settings(프로젝트 화면 오른쪽 위 톱니바퀴) > General

1

Thread effort , 기본값 High

새 프로젝트는 스레드마다 Opus · High 로 돕니다. 공식 문서 원문: "A new project runs every thread on Opus at high effort, which draws on your plan fastest". 링크 확인·오타 같은 가벼운 일이면 Thread effort 를 낮추고, 무거운 일만 High 로 두세요.

2

Auto-continue when usage limits reset , 기본 켜짐

한도에 닿은 스레드는 기다렸다가 한도가 리셋되면 알아서 이어서 돕니다. 공식 문서 원문: "work you left running starts using your next usage window without a message from you". 다음 한도 창까지 쓰기 싫으면 이 스위치를 끄세요.

하나 더 , 코디네이터에게 이렇게 말해 두기

"스레드는 시작 전에 먼저 제안하고, 한 번에 몇 개씩만 돌려줘." 공식 문서도 처음엔 이렇게 시키고, 결과가 원하는 대로 나오면 풀라고 적어 둡니다. 단 이건 설정이 아니라 부탁이라 강제 상한은 아닙니다(강제 상한은 하루 새 스레드 200개).
