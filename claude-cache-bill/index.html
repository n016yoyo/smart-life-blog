왜 계산해봤냐면

새 모델로 갈아탈까 하고 가격표 두 장을 폈는데 네 칸 중 세 칸이 글자까지 같았습니다. 입력 $10, 출력 $50, 캐시 쓰기 $12.50. 그럼 아무거나 써도 되겠다 싶었는데, 캐시 읽기 한 칸만 네 배였어요. 겨우 75센트 차이라 넘길 뻔했습니다.

※ 아래 숫자는 제 계정의 2026년 9월 6일 7일치입니다. 저는 정액제(Max)라 실제로 이 금액을 내지 않습니다. API 정가로 곱하면 이렇다는 환산값이에요. 여러분 값은 쓴 만큼 다릅니다.

그 한 칸이 왜 전부가 되나

대화가 길어질수록 앞부분을 통째로 다시 읽습니다

1

한 번 시킬 때마다 처음부터 다시 읽는다

클로드에게 뭘 시키면 지금까지의 대화를 통째로 다시 읽고 답합니다. 열 번 시키면 새로 쓴 건 열 개인데 읽은 건 쉰다섯 개예요. 턴이 늘수록 다시 읽기가 제곱으로 늡니다.

2

그 다시 읽기가 캐시 읽기다

제 7일 입력 토큰 36억 개 중 97.7%가 캐시 읽기였습니다. 순수 입력은 0.1%도 안 됩니다.

3

그래서 세 칸이 같아도 소용이 없다

총액의 대부분이 그 한 칸에서 나오니까요. 항목별로 곱하면 캐시 읽기만 $886 대 $3,543이고, 나머지 세 칸은 양쪽이 완전히 같습니다.

클로드 코드를 쓰신다면 그대로 붙여넣으면 됩니다

먼저 이렇게 하세요

  1. 아무 폴더나 열고 cost.js 라는 이름으로 저장합니다.
  2. 터미널에서 node cost.js 를 칩니다.
  3. 끝입니다. 아무것도 설치하지 않고, 어디로도 보내지 않습니다.

읽는 건 ~/.claude/projects/**/*.jsonl 뿐입니다. 클로드 코드가 자기 대화 기록을 남기는 자리예요. 값을 바꾸고 싶으면 맨 위 요금 상수만 고치면 다른 모델로도 계산됩니다.

cost.js
// 내 실제 클로드 코드 사용량(최근 7일)을 GPT-6 Astra 와 Claude Fable 5.1 **API 정가**로 각각 곱한다.
//   ★우리는 정액제(Max)라 이 금액을 실제로 내지 않는다. 화면·대사에 반드시 "API 정가로 곱하면" 을 박는다
//     (reel_waldo2 라벨 오류 재현 방지 , 숫자는 안 틀려도 이름이 틀릴 수 있다).
// 요금 출처(둘 다 공식 페이지 실캡처, evidence/shots/):
//   Astra      platform.openai.com/docs/pricing   입력 $10 / 캐시읽기 $1.00  / 캐시쓰기 $12.50 / 출력 $50
//   Fable 5.1  platform.claude.com/docs/en/about-claude/pricing
//              입력 $10 / 캐시읽기(Cache hits and refreshes) $0.25 / 5m 캐시쓰기 $12.50 / 출력 $50
//   ★각주까지 같이 찍는다: Fable 5.1·Mythos 5.1 만 base input 의 0.025배, 나머지 전 모델은 0.1배 = 4배 차이의 근거.
// 토큰 출처: ~/.claude/projects/**/*.jsonl 의 message.usage (reel_pricedeadline/cost.js 와 같은 세는 규칙)
// 실행: node docs/reel_astracache/evidence/cost.js [--json]
const fs = require("fs"), path = require("path"), os = require("os");
const ROOT = path.join(os.homedir(), ".claude", "projects");
const DAYS = 7, since = Date.now() - DAYS * 864e5;
const FABLE = { in: 10, out: 50, cr: 0.25, cw: 12.50 };
const ASTRA = { in: 10, out: 50, cr: 1.00, cw: 12.50 };

const walk = (d, o = []) => {
  for (const e of fs.readdirSync(d, { withFileTypes: true })) {
    const p = path.join(d, e.name);
    if (e.isDirectory()) walk(p, o); else if (e.name.endsWith(".jsonl")) o.push(p);
  } return o;
};
let t = { in: 0, out: 0, cr: 0, cw: 0 }, calls = 0, files = 0;
for (const f of walk(ROOT)) {
  if (fs.statSync(f).mtimeMs < since) continue; files++;
  for (const line of fs.readFileSync(f, "utf8").split("\n")) {
    if (!line.trim()) continue; let j; try { j = JSON.parse(line); } catch { continue; }
    const u = j.message && j.message.usage; if (!u) continue;
    if (j.timestamp && Date.parse(j.timestamp) < since) continue;
    calls++; t.in += u.input_tokens || 0; t.out += u.output_tokens || 0;
    t.cr += u.cache_read_input_tokens || 0; t.cw += u.cache_creation_input_tokens || 0;
  }
}
const bill = r => (t.in * r.in + t.out * r.out + t.cr * r.cr + t.cw * r.cw) / 1e6;
const totalIn = t.in + t.cr + t.cw;
const f = bill(FABLE), a = bill(ASTRA);
const R = {
  at: new Date().toISOString(), days: DAYS, files, calls,
  tokens: t, total_input: totalIn, cache_read_share: +(t.cr / totalIn * 100).toFixed(1),
  fable: +f.toFixed(2), astra: +a.toFixed(2), diff: +(a - f).toFixed(2), ratio: +(a / f).toFixed(2),
  rows: [
    { label: "입력",      left: +(t.in * 10 / 1e6).toFixed(2),   right: +(t.in * 10 / 1e6).toFixed(2) },
    { label: "캐시 쓰기", left: +(t.cw * 12.5 / 1e6).toFixed(2), right: +(t.cw * 12.5 / 1e6).toFixed(2) },
    { label: "출력",      left: +(t.out * 50 / 1e6).toFixed(2),  right: +(t.out * 50 / 1e6).toFixed(2) },
    { label: "캐시 읽기", left: +(t.cr * 0.25 / 1e6).toFixed(2), right: +(t.cr * 1.00 / 1e6).toFixed(2) },
  ],
  cr_only: { fable: +(t.cr * FABLE.cr / 1e6).toFixed(2), astra: +(t.cr * ASTRA.cr / 1e6).toFixed(2) },
};
if (process.argv.includes("--json")) { console.log(JSON.stringify(R, null, 1)); process.exit(0); }
console.log(`최근 ${DAYS}일 · 세션파일 ${files}개 · 요청 ${calls.toLocaleString()}건`);
console.log(`입력 합계 ${totalIn.toLocaleString()} 토큰  그중 캐시 읽기 ${t.cr.toLocaleString()} = ${R.cache_read_share}%`);
console.log(`출력 ${t.out.toLocaleString()} 토큰`);
const usd = (v) => "$" + Math.round(v).toLocaleString("en-US");
// ★고정폭 터미널에서 한글은 두 칸을 먹는다 , 길이로 세면 표가 어긋난다(2026-09-06 실측)
const wcw = (s) => [...String(s)].reduce((n, c) => n + (/[\u1100-\u11FF\u3000-\u303F\u3130-\u318F\uAC00-\uD7AF\uFF00-\uFF60]/.test(c) ? 2 : 1), 0);
const pad = (s, n) => String(s) + " ".repeat(Math.max(0, n - wcw(s)));
const lpad = (s, n) => " ".repeat(Math.max(0, n - wcw(s))) + String(s);
console.log("");
console.log(`API 정가 환산   ${pad("", 6)}${lpad("Fable 5.1", 10)}${lpad("Astra", 10)}`);
for (const r of R.rows) console.log(`  ${pad(r.label, 12)}${lpad(usd(r.left), 10)}${lpad(usd(r.right), 10)}`);
console.log(`  ${pad("합계", 12)}${lpad(usd(R.fable), 10)}${lpad(usd(R.astra), 10)}`);
console.log(`차이 ${usd(R.diff)} · ${R.ratio}배   (정액제라 실제 청구 아님)`);
