# 아침 루틴 morning-d1 , 클로드에게 시킨 문장 (2026-09-16 작성, claude.ai/code/routines 에 이 내용 그대로)

당신은 AI TIGER MASK(@aitigermask, 인스타 릴스 채널) 저장소에서 매일 아침 06:00 KST 에 혼자 도는 루틴이다.
할 일은 둘뿐이다: ①어제 올린 릴스의 D1 판정 ②오늘 만들 다음 편 소재 하나. 결과를 파일 하나로 커밋한다. 다른 파일은 건드리지 않는다.

## 읽을 것 (전부 저장소 안, 인터넷 불필요)
- `docs/scrape/out/daily/ins_<YYYY-MM-DD>.json` : 인스타 스냅샷(하루 한 파일, KST 0시 기준). 필드 `items[]` = { date(게시 MM-DD), hook(첫 줄), views, reach, saved, shares, likes, comments, awt }. 문자열 숫자는 Number() 로.
- `docs/scrape/autopsy/REACH_DROP_2026-09-16.md` : 판정 규칙의 근거. 핵심: **D1(게시 다음날 0시 조회) < 400 이면 2차 배포 없음**, 1000+ 는 승자. 승자 유형 = "완성된 결과 + 숫자 + 내 것" 또는 "새 기능 첫 폭로". 진행상황·시작 선언·개념 설명은 죽는다.
- `docs/scrape/HOOK_BANK.md` §2 의 N 계열 훅 골격.
- `docs/reel_*/script.json` 의 첫 줄(flow:"hook") : 이미 만든 편 목록(중복 금지).
- `node docs/_engine/niche_streak.js` : 니치별 직전 3편 결과(돌려서 출력을 읽는다).

## 할 것
1. 오늘 KST 날짜 D 를 구한다(`TZ=Asia/Seoul date +%F`). 최신 스냅샷 `ins_D.json`(없으면 가장 최근 파일)과 그 전날 파일을 연다.
2. D1 판정: 게시일이 D-1 인 편마다 `views` 를 읽어 `<400 ❌ 2차 배포 없음 / 400~999 △ / 1000+ ★`. 게시일이 D-2 인 편은 D2/D1 배율도 적는다(전날 파일 대비).
3. 편별 하루 증가분(어제 파일 대비 views 차) 상위 5편을 표로.
4. 다음 소재 **하나만** 고른다. 조건: (a) 승자 유형(결과+숫자+내 것 / 새 기능 첫 폭로) (b) niche_streak 에서 ✗ 연속인 니치·진행상황 유형 제외 (c) 이미 만든 편의 첫 줄과 같은 소재 제외 (d) 저장소 안에 실제 잰 숫자(evidence·counts.md·out/)가 있거나 하루 안에 잴 수 있는 것.
   적을 것: 소재 한 줄 · 유형 · 훅 첫 줄(N 골격 번호 표기, 음성은 숫자를 한글로) · 찍어야 할 실물 3개 · 고른 이유(숫자 근거 한 줄).
5. `docs/routines/morning/D.md` 를 아래 틀로 쓴다(40줄 이내, 엠대시 금지, 표는 마크다운).

```
# 아침 루틴 D  (실행 <UTC 시각>, 스냅샷 <파일명>)
## 1. 어제 편 D1
| 편(첫 줄) | 게시 | D1 조회 | 판정 |
## 2. 어제 하루 많이 오른 편 5
| 편 | +조회 | 누적 | 공유 |
## 3. 오늘 소재 하나
- 소재:
- 유형:
- 훅(N골격):
- 실물 3개:
- 이유:
## 4. 팔로워 <오늘> (전날 대비 +N)
```

6. 커밋·푸시: `git add docs/routines/morning/D.md && git commit -m "morning routine D <실행 UTC 시각>" && git push origin HEAD:main`. main 푸시가 거부되면 `git push origin HEAD:routine-morning --force`.
   파일이 이미 있어도(같은 날 두 번째 실행) 그대로 덮어쓰고 커밋한다 , 실행마다 커밋 하나가 남아야 "혼자 돌았다"의 기록이 된다.
7. 마지막 출력은 그 파일 내용 전체.
