AI TIGER MASK

클로드에게 유튜브 화면까지 보여주기

클로드는 유튜브 자막은 읽습니다. 그런데 화면은 못 봅니다. 슬라이드도, 이름 자막도, 띄워놓은 코드도 안 보입니다. 그걸 떠서 같이 넘겨주는 도구입니다.

코드 전문 공개 키 불필요 비용 0원
👀 지금까지 … 명이 봤어요
왜 반쪽만 읽히나 준비물 코드 전문 돌려보기 실제 실행 기록 막히는 곳 더 나가기
WHY

왜 반쪽만 읽히나

클로드에게 유튜브 링크를 주고 요약시키면 꽤 그럴듯한 답이 옵니다. 실제로 자막을 받아 읽기 때문입니다. 그런데 영상 자체는 못 봅니다. 모델이 영상 입력을 받지 않습니다.

그래서 화면에만 있고 말로는 안 한 것이 통째로 빠집니다.

  • 발표 슬라이드의 제목과 항목
  • 화면 아래 뜨는 이름·직함 자막 (지금 누가 말하는지)
  • 띄워놓은 코드, 대시보드, 그래프
  • 손으로 가리키는 것, 화이트보드
발표자가 "여기 보시면"이라고만 하고 넘어간 것들입니다. 자막에는 "여기 보시면"만 남습니다. 정작 무엇을 보라는 건지는 화면에 있고, 그 화면을 클로드는 못 봅니다.
개발을 몰라도 됩니다. 아래 코드를 클로드 코드에게 그대로 저장시키고 명령만 치면 됩니다. 필요한 것(yt-dlp)도 클로드가 깔아줍니다.
PREP

준비물

무엇왜 필요한가
Node.js코드를 돌리는 프로그램입니다. 없으면 nodejs.org 에서 LTS 를
yt-dlp유튜브에서 자막·영상을 받아옵니다. 클로드에게 "yt-dlp 깔아줘"라고 하면 됩니다
ffmpeg화면을 뜨고 한 장으로 붙일 때만 씁니다(--화면 옵션). 자막만 쓸 거면 없어도 됩니다

가입도, 결제도, 키 발급도 없습니다.

CODE

코드 전문 , 파일 하나

폴더를 하나 만들고 brief.js 로 저장하세요.

brief.js
// 유튜브 영상을 클로드가 "읽고 보게" 만든다.
//   사용: node brief.js "<유튜브 주소>" [언어] [--화면]
//     node brief.js "https://youtu.be/xxxx"            , 자막만(빠름)
//     node brief.js "https://youtu.be/xxxx" ko --화면   , 자막 + 화면 몽타주
//     node brief.js "https://youtu.be/xxxx" en --화면
//
// 하는 일
//   ① 자막 받기 → 중복·태그 걷어내기 → 분 단위로 묶기 → out/<영상id>.md
//   ② `--화면` 이면 프레임을 일정 간격으로 떠서 타일로 붙인다 → out/<영상id>_screens/
//      ★클로드는 영상을 못 본다. 자막을 줘도 **화면에 뭐가 떠 있었는지는 모른다.**
//        슬라이드·코드·데모 화면이 중요한 영상은 이 몽타주가 있어야 제대로 읽는다.
// ★API 키도 계정도 필요 없다. yt-dlp 가 공개 자막을 그대로 받아온다.
const fs = require("fs"), path = require("path"), { execFileSync } = require("child_process");

const url = process.argv[2];
const lang = (process.argv[3] || "ko").replace(/^--.*/, "") || "ko";
const wantScreens = process.argv.includes("--화면") || process.argv.includes("--screens");
if (!url) {
  console.log(`사용: node brief.js "<유튜브 주소>" [언어]

  node brief.js "https://youtu.be/xxxx"       , 한국어 자막
  node brief.js "https://youtu.be/xxxx" en    , 영어 자막

★yt-dlp 가 필요합니다. 없으면: pip install -U yt-dlp  (또는 클로드에게 "yt-dlp 깔아줘")`);
  process.exit(0);
}

const OUT = path.join(__dirname, "out");
const TMP = path.join(__dirname, ".tmp");
fs.mkdirSync(OUT, { recursive: true });
fs.rmSync(TMP, { recursive: true, force: true });
fs.mkdirSync(TMP, { recursive: true });

// ★쿠키가 있으면 쓴다 , 유튜브가 영상 다운로드에 403 을 내는 경우가 있다(자막은 대개 그냥 된다)
const COOKIES = [path.join(__dirname, ".yt_cookies.txt"), path.join(__dirname, "../scrape/.yt_cookies.txt")]
  .find(p => fs.existsSync(p));
// ★★유튜브는 **미디어 바이트**에만 서명 검사를 건다. 그래서 경로를 둘로 나눈다(2026-08-19 실측).
//   자막·메타 = 일반 yt-dlp, **쿠키 없이**. 쿠키를 붙이면 인증 경로로 가서 PO token 을 요구하고 실패한다.
//   영상     = self-contained 바이너리 + 쿠키 + deno EJS 솔버. 이게 없으면 403.
const BIN_MEDIA = fs.existsSync(process.env.HOME + "/.local/bin/yt-dlp_linux")
  ? process.env.HOME + "/.local/bin/yt-dlp_linux" : "yt-dlp";
const ytEnv = { ...process.env, PATH: `${process.env.HOME}/.deno/bin:${process.env.PATH}` };

// 메타·자막 , 익명이 정답
const yt = (args) => execFileSync("yt-dlp", args, { encoding: "utf8", maxBuffer: 1 << 28 });
// 영상 , 쿠키 + EJS
const ytMedia = (args) => execFileSync(BIN_MEDIA,
  [...(COOKIES ? ["--cookies", COOKIES] : []), "--remote-components", "ejs:github", ...args],
  { encoding: "utf8", maxBuffer: 1 << 28, env: ytEnv });

// ── 1. 제목·길이 먼저
let title = "", durSec = 0, vid = "";
try {
  const meta = JSON.parse(yt(["--skip-download", "--dump-json", "--no-warnings", url]));
  title = meta.title || "";
  durSec = meta.duration || 0;
  vid = meta.id || "video";
} catch (e) {
  console.log("영상 정보를 못 읽었습니다:", String(e.message).split("\n")[0]);
  process.exit(1);
}
const hhmmss = (s) => [Math.floor(s / 3600), Math.floor(s / 60) % 60, Math.floor(s % 60)]
  .map((v, i) => (i === 0 && v === 0 ? null : String(v).padStart(2, "0"))).filter(Boolean).join(":");

console.log(`영상: ${title}`);
console.log(`길이: ${hhmmss(durSec)}`);

// ── 2. 자막 받기 , 사람이 단 것 우선, 없으면 자동 생성
let vtt = null, kind = "";
for (const [flag, label] of [["--write-subs", "사람이 단 자막"], ["--write-auto-subs", "자동 생성 자막"]]) {
  try {
    yt([flag, "--skip-download", "--sub-langs", `${lang}.*,${lang}`, "--sub-format", "vtt",
        "-o", path.join(TMP, "s.%(ext)s"), "--no-warnings", url]);
    const hit = fs.readdirSync(TMP).find(f => f.endsWith(".vtt"));
    if (hit) { vtt = fs.readFileSync(path.join(TMP, hit), "utf8"); kind = label; break; }
  } catch {}
}
if (!vtt) {
  console.log(`\n"${lang}" 자막이 없습니다. 다른 언어로 다시 해보세요 , 예: node brief.js "${url}" en`);
  process.exit(1);
}
const rawBytes = Buffer.byteLength(vtt);

// ── 3. 정리 , VTT 는 같은 줄을 여러 번 반복해서 내보낸다(자동 자막이 특히 심하다)
const cues = [];
for (const block of vtt.replace(/\r/g, "").split("\n\n")) {
  const m = block.match(/(\d{2}:\d{2}:\d{2})\.\d{3}\s+-->/);
  if (!m) continue;
  const text = block.split("\n").slice(1)
    .filter(l => !/-->/.test(l))
    .join(" ")
    .replace(/<[^>]*>/g, "")          // <c> 같은 타이밍 태그
    .replace(/&nbsp;|&amp;/g, " ")
    .replace(/\s+/g, " ").trim();
  if (text) cues.push({ t: m[1], text });
}
// 직전 줄에 이미 들어 있는 조각은 버린다
const clean = [];
for (const c of cues) {
  const prev = clean.length ? clean[clean.length - 1].text : "";
  if (prev.endsWith(c.text) || prev === c.text) continue;
  if (c.text.startsWith(prev) && prev) { clean[clean.length - 1].text = c.text; continue; }
  clean.push(c);
}

// ── 4. 분 단위로 묶기 , 클로드가 "몇 분쯤"으로 짚을 수 있게
const byMin = new Map();
for (const c of clean) {
  const [h, m] = c.t.split(":").map(Number);
  const key = h * 60 + m;
  if (!byMin.has(key)) byMin.set(key, []);
  byMin.get(key).push(c.text);
}
const lines = [...byMin.entries()].sort((a, b) => a[0] - b[0])
  .map(([min, arr]) => `[${String(Math.floor(min / 60)).padStart(2, "0")}:${String(min % 60).padStart(2, "0")}] ${arr.join(" ")}`);

// ── 5. 화면 몽타주 , 자막은 "말한 것"만 담는다. 슬라이드·코드·데모는 여기 있다.
let shots = 0, sheets = 0, shotDir = "";
if (wantScreens) {
  shotDir = path.join(OUT, `${vid}_screens`);
  fs.rmSync(shotDir, { recursive: true, force: true });
  fs.mkdirSync(shotDir, { recursive: true });
  const gap = durSec > 3600 ? 60 : durSec > 1200 ? 30 : 10;   // 긴 영상일수록 성기게
  process.stdout.write(`화면: ${gap}초 간격으로 뜨는 중...`);
  // ★한 번 받은 영상은 남겨둔다 , 같은 영상을 다시 분석할 때 몇 분을 아낀다(용량이 부담되면 지우면 된다).
  const cached = path.join(OUT, `${vid}_video.mp4`);
  const raw = fs.existsSync(cached) ? cached : path.join(TMP, "v.mp4");
  try {
    if (fs.existsSync(cached)) {
      process.stdout.write(` (받아둔 영상 재사용)`);
    } else {
      ytMedia(["-f", "134+140/18/worst[ext=mp4]/worst", "--merge-output-format", "mp4",
          "-o", raw, "--no-warnings", url]);
      try { fs.copyFileSync(raw, cached); } catch {}
    }
    execFileSync("ffmpeg", ["-v", "error", "-i", raw, "-vf", `fps=1/${gap},scale=320:-2`,
      path.join(TMP, "s%04d.jpg"), "-y"], { maxBuffer: 1 << 28 });
    const list = fs.readdirSync(TMP).filter(f => /^s\d+\.jpg$/.test(f)).sort();
    shots = list.length;
    const PER = 24;                                            // 시트 한 장에 24컷(6x4)
    // ★개별 -i 를 24개 주면 ffmpeg 가 각각을 이미지 **시퀀스**로 읽어 4컷짜리가 나온다.
    //   tile 필터에 -start_number 로 범위를 주는 쪽이 맞다(2026-08-19 실측).
    for (let i = 0; i < list.length; i += PER) {
      execFileSync("ffmpeg", ["-v", "error", "-start_number", String(i + 1),
        "-i", path.join(TMP, "s%04d.jpg"), "-frames:v", "1",
        "-vf", "tile=6x4:padding=4:color=0x1e1b17",
        path.join(shotDir, `sheet_${String(++sheets).padStart(2, "0")}.jpg`), "-y"],
        { maxBuffer: 1 << 28 });
    }
    console.log(` ${shots}컷 → 시트 ${sheets}장`);
  } catch (e) {
    console.log(` 실패(${String(e.message).split("\n")[0].slice(0, 60)}) , 자막만 저장합니다`);
    shots = 0; sheets = 0;
  }
}

const md = `# ${title}\n\n출처: ${url}\n길이: ${hhmmss(durSec)} · ${kind}\n\n` +
  `> 아래는 이 영상의 자막을 분 단위로 묶은 것입니다. 클로드에게 이 파일을 주고\n` +
  `> "훅이 뭔지, 어떤 순서로 풀어가는지, 건너뛰어도 되는 구간이 어딘지" 물어보세요.\n` +
  (sheets ? `>\n> ★화면도 같이 떴습니다: \`${vid}_screens/sheet_01.jpg\` 부터 ${sheets}장 (${shots}컷).\n` +
            `> **그 이미지들도 같이 열어보라고 하세요.** 자막에는 슬라이드·코드·데모 화면이 안 들어 있습니다.\n` : "") +
  `\n` + lines.join("\n") + "\n";

const outPath = path.join(OUT, `${vid}.md`);
fs.writeFileSync(outPath, md);
fs.rmSync(TMP, { recursive: true, force: true });

const kb = (b) => b >= 1 << 20 ? (b / (1 << 20)).toFixed(2) + " MB" : Math.round(b / 1024) + " KB";
console.log(`자막: ${kind} · ${cues.length}조각 → ${clean.length}줄 → ${lines.length}분`);
console.log(`크기: ${kb(rawBytes)} → ${kb(Buffer.byteLength(md))}`);
console.log(`\n저장: ${outPath}`);
if (sheets) console.log(`화면: ${shotDir}/ (${shots}컷 · 시트 ${sheets}장)`);
console.log(`다음: 클로드에게 이 파일을 주고 "훅·구조·건너뛸 구간 알려줘" 라고 하세요.`);
RUN

TRAPS

막히는 곳

⚠ 자막은 되는데 영상만 403

유튜브는 영상 데이터에만 서명 검사를 겁니다. 자막·제목은 그냥 받아지는데 영상만 막히는 게 정상입니다. 그래서 이 코드는 경로를 둘로 나눠 놨습니다.

서버나 컨테이너에서 돌린다면 ①로그인 쿠키 ②yt-dlp 대신 self-contained 바이너리 ③JS 솔버가 필요할 수 있습니다. 일반 PC 에서는 대개 그냥 됩니다.

⚠ 자막에 쿠키를 붙이면 오히려 실패한다

쿠키를 붙이면 인증 경로로 가면서 별도 토큰을 요구합니다. 자막은 로그인 없이 받는 게 맞습니다. 코드가 그렇게 나뉘어 있는 이유입니다.

⚠ 자막이 없습니다

그 영상에 그 언어 자막이 없습니다. en 으로 다시 하거나 자막이 있는 영상으로 바꾸세요.

⚠ 화면 뜨는 게 오래 걸린다

영상을 받아야 해서 그렇습니다. 한 번 받으면 out/ 에 남겨두고 다음부터는 재사용합니다. 용량이 부담되면 그 파일만 지우면 됩니다.
