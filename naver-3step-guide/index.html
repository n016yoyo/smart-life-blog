MAP

뭘 세 개로 나눴나

블로그 한 편을 올리는 일은 사실 세 가지 다른 일입니다. 한 번에 다 자동화하려니까 어려운 거지, 나눠 놓으면 각각은 프롬프트 한 장짜리입니다.

단계손으로 하면자동화하면
1단 · 발행글 하나에 한두 시간크롬이 실제 스마트에디터에 사람 속도로 타이핑, 사진 삽입, 임시저장
2단 · 글감"오늘 뭐 쓰지"로 한참한 주치 유튜브 트렌드를 모아 내 니치 신호어로 점수화, 1등만 남김
3단 · 이웃이웃 39곳이면 39분본문을 끝까지 읽고 그 내용을 짚은 댓글, 공감까지
공통 원리는 하나입니다. Claude Code가 짠 코드가 진짜 크롬을 열어 사람처럼 조작합니다. 네이버에 글쓰기 공식 API가 없어서(2026년 현재 오픈 API는 검색만) 이 방식을 씁니다.
ORDER

만드는 순서는 1 → 3 → 2

번호 순서대로 만들지 않아도 됩니다. 실제로 편한 순서는 이겁니다.

  1. 1단 발행을 먼저. 로그인 넘겨주기, 에디터 진입, 팝업 처리 같은 기본 벽을 여기서 다 넘습니다. 나머지 두 개는 이 위에 얹힙니다.
  2. 그다음 3단 이웃 댓글. 글을 매일 못 올려도 이웃 관리는 매일 필요합니다. 체감 절약이 제일 큽니다.
  3. 마지막에 2단 글감. 유튜브 API 키를 새로 받아야 해서 준비물이 하나 늘어납니다. 앞의 둘이 돌아간 뒤에 붙이세요.
세 개를 한 프롬프트로 시키지 마세요. 어디서 막혔는지 알 수 없어집니다. 하나가 끝까지 돌아가는 걸 눈으로 본 다음 다음 것으로 넘어가는 편이 결국 빠릅니다.

- Playwright로 크롬을 띄우고 headless는 끄기(내가 직접 로그인할 수 있게)
- 내가 로그인을 마칠 때까지 기다렸다가, 로그인 완료를 감지하면
  storageState를 naver_state.json 으로 저장
- 그 파일은 .gitignore 에 넣어서 절대 커밋되지 않게 해줘

★중요: 저장할 때 NID_AUT 와 NID_SES 쿠키가 실제로 들어있는지 먼저 확인하고,
없으면 파일을 덮어쓰지 말고 경고만 출력해줘.
왜 저 ★가 중요하냐면, 네이버 로그인 쿠키는 만료값이 -1인 세션 쿠키라 브라우저를 닫으면 사라집니다. 이걸 모르고 종료 후에 저장하면 실행할 때마다 로그인이 지워집니다. 저희도 한동안 로그아웃 상태로 돌렸습니다.
STEP 1

1단, 크롬이 대신 타이핑합니다

1

제목·본문을 한 글자씩, 사진까지 넣고 임시저장

난이도 보통 · 처음 만드는 데 30분쯤

Claude가 짠 코드가 크롬을 열고 실제 스마트에디터에 들어가서, 제목과 본문을 사람 속도로 타이핑하고 문단 사이에 사진을 끼워 넣습니다. 네이버 입장에선 누가 손으로 쓰는 것과 구분되지 않습니다.

Claude Code에 그대로 붙여넣기
이 주제로 네이버 블로그 초안을 써줘: (여기에 주제).
그리고 이 자동화 규칙 세 가지로 실행해줘.
하나, 브라우저를 열어 실제 네이버 스마트에디터에 들어가 줘.
둘, 제목과 본문을 사람 속도로(한 글자씩) 타이핑하고, 문단 사이에 사진을 자동으로 넣어 줘.
셋, 발행은 하지 말고 임시저장까지만 해줘. 전 과정은 영상으로 녹화해 줘.
1단 자세히 보기, 쿠키 넣는 법과 실전 함정 6가지 →
발행 버튼은 사람이 누릅니다. 자동화는 임시저장까지입니다. 검토 없이 자동 발행하면 오타·잘못된 사진이 그대로 공개되고, 대량 자동 발행은 네이버가 스팸으로 볼 수 있습니다.
STEP 2

2단, 뭘 쓸지도 숫자로 고릅니다

2

한 주치 유튜브 트렌드를 점수화해 1등 글감만 남기기

난이도 쉬움 · 유튜브 API 키 발급 10분 필요(무료)

1단에서는 글감을 사람이 줬습니다. 여기서 한 단계 더 가면 "오늘 뭐 쓰지"까지 넘길 수 있습니다. 이번 주에 터진 영상을 모아서, 내 독자가 반응하는 신호어가 제목에 들어가면 가점을 주고, 점수 순으로 줄 세워 1등을 고릅니다. 감이 아니라 숫자입니다.

API 키 받기: console.cloud.google.com 접속 → 새 프로젝트 → YouTube Data API v3 검색 후 사용 설정 → 사용자 인증 정보 → API 키. 하루 1만 요청까지 무료라 개인용으론 넘칩니다.

Claude Code에 그대로 붙여넣기
유튜브 API 키로 "글감 자동 선정"을 만들어줘.
하나, 이번 주에 올라온 내 주제 관련 유튜브 영상을 조회수 순으로 최대한 많이 수집해줘. (내 주제: 여기에 입력)
둘, 제목에 내 독자가 반응하는 신호어가 들어가면 가점을 줘. (내 신호어: 예시로 무료·돈·초보·따라하기, 내 니치에 맞게 바꿔줘)
셋, 점수 순으로 줄 세워서 1등을 이번 글감으로 선정하고, 왜 선정했는지 근거(점수·조회수)를 파일로 남겨줘.
넷, 선정된 글감으로 위에서 만든 블로그 자동 글쓰기를 이어서 실행해줘. 발행은 하지 말고.
2단 자세히 보기, 실제 점수표 화면 →
신호어는 반드시 내 니치로 바꾸세요. 예시(무료·돈·따라하기)는 저희 독자 기준입니다. 점수 기준이 곧 "내 독자가 뭘 클릭하는가"라서, 이걸 자기 독자에 맞게 잡는 게 이 단계의 절반입니다.
STEP 3

3단, 이웃 글을 읽고 댓글을 답니다

3

본문 전문을 읽고 그 내용을 짚는 댓글, 공감까지

난이도 보통 · 처음엔 --dry로 문장만 확인

흔한 댓글 봇은 아무 글에나 같은 인사말을 붙입니다. 받는 사람도 압니다. 이건 본문을 통째로 읽고 그 내용을 짚어 씁니다. 글을 안 읽으면 나올 수 없는 문장이 나옵니다.

Claude Code에 그대로 붙여넣기
네이버 서로이웃 순회 자동화를 만들어줘.

동작 순서
1) 저장해둔 naver_state.json 으로 로그인 상태를 복원하고
   https://section.blog.naver.com/BlogHome.naver 에서 이웃 새글 목록을 수집
2) 위에서부터 N개 글을 방문해서, 각 글의 본문 전체를 텍스트로 읽기
   (요약 말고 전문. .se-main-container 또는 #postViewArea)
3) 읽은 제목·본문을 Claude Code CLI(claude -p)에 넘겨 댓글 한 줄 생성
   규칙: 35자 이내 / 글에 실제로 나온 구체적 내용을 하나 짚을 것 /
        "잘 보고 가요" 같은 아무 글에나 붙는 인사 댓글 금지
4) 공감(하트) 누르고, 생성된 댓글 등록
5) 다음 글까지 3~5초 랜덤 대기

옵션
--dry      댓글을 생성만 하고 등록은 안 함(처음엔 이걸로 확인)
--nolike   공감도 누르지 않음
--rec      전 과정 화면 녹화

실행 결과(방문수·읽은 글자수·댓글·공감)를 JSON으로 저장해줘.
