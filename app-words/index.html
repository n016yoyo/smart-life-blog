앱 용어 8개, 식당 하나로

서버·창고·주문·개업·일지·경고등·열쇠·번호표. 어려워 보이는 여덟 개를 식당 하나로 다 설명합니다. 각 용어마다 클로드한테 그대로 시킬 말까지 붙였습니다.

Claude Code 이것만 코딩 0줄 용어 8개
👀 지금까지 … 명이 봤어요
왜 식당인가 서버 DB API 배포 깃 에러 API 키 인증 만드는 순서 지금 시작하기
WHY

왜 식당으로 설명하나

앱 만들기를 배울 때 막히는 건 코딩이 아니라 말입니다. 서버가 뭔지 모르는데 "서버에 배포하라"는 말을 들으면 거기서 끝납니다.

그런데 이 여덟 개는 전부 식당 하나로 설명이 됩니다. 앱이 식당이라고 치면, 나머지는 그 식당의 부품입니다.

앱 = 식당
가게 불이 서버, 창고가 DB, 옆 가게 주문이 API, 문 열고 간판 거는 게 배포입니다. 나머지 넷은 장사하다 겪는 일들이고요.

아래 여덟 개를 다 읽는 데 3분이면 됩니다. 각각 클로드한테 시킬 말 3개가 붙어 있으니, 읽고 바로 따라 하시면 됩니다.

TIER 1 · 앱이 돌아가려면 있어야 하는 것

이 넷이 없으면 앱이 아예 성립하지 않습니다.

01

서버

Server

앱을 24시간 켜두는, 늘 깨어 있는 컴퓨터입니다. 내 노트북을 껐는데도 남들이 계속 쓸 수 있는 건 서버가 대신 켜져 있어서예요.

🍽 식당에선 가게 불입니다. 내가 퇴근해도 불은 켜져 있어야 손님이 들어오죠.
클로드한테 이렇게 말하세요
  • 서버에 올려줘
  • 꺼지지 않게 해줘
  • 몰려도 버티게 해줘
02

디비

DB, Database

앱의 모든 정보를 쌓아두는 창고입니다. 회원·글·주문을 행과 열로 정리해두니까, 만 개가 쌓여도 필요한 걸 바로 꺼냅니다.

🍽 식당에선 창고와 주문 장부입니다. 재료가 어디 있고 누가 뭘 시켰는지 여기 있어야 장사가 됩니다.
클로드한테 이렇게 말하세요
  • 이거 디비에 저장해줘
  • 이 회원 찾아줘
  • 최신순으로 정렬해줘
03

에이피아이

API

결제·지도·로그인처럼 어려운 기능을 직접 안 만들고, 남이 만들어둔 걸 갖다 붙이는 것입니다. 몇 달 걸릴 일이 몇 분에 끝납니다.

🍽 식당에선 옆 가게 주문입니다. 디저트까지 직접 만들 필요 없이 잘하는 집에 시키면 되죠.
클로드한테 이렇게 말하세요
  • 결제 붙여줘
  • 지도 넣어줘
  • 로그인 연결해줘
04

배포

Deploy

내 컴퓨터에서만 되던 앱을 인터넷에 올려서, 남들이 주소만 알면 들어올 수 있게 하는 것입니다. 링크 하나 나오면 끝입니다.

🍽 식당에선 문 열고 간판 거는 것입니다. 다 차려놔도 문을 안 열면 아무도 못 들어옵니다.
클로드한테 이렇게 말하세요
  • 인터넷에 배포해줘
  • 접속 주소 만들어줘
  • 공유 링크 뽑아줘
TIER 2 · 장사하다 반드시 겪는 것

여기서 포기하는 사람이 많은데, 사실 전부 클로드가 해결합니다.

05

깃

Git

만드는 과정을 매 순간 저장해두는 기록장입니다. 게임 세이브 포인트라고 보시면 됩니다. 망쳐도 마지막 저장 지점으로 5초 만에 돌아갑니다.

🍽 식당에선 요리 일지입니다. 레시피 바꿀 때마다 적어두면, 망했을 때 어제 걸로 돌아가면 됩니다.
클로드한테 이렇게 말하세요
  • 지금 상태 저장해줘
  • 잘 되면 또 저장해줘
  • 망쳤으니 되돌려줘
이게 있어야 실험을 맘껏 합니다. 되돌릴 수 있으니 겁낼 게 없어요. 코딩 안전벨트입니다.
06

에러

Error, Debugging

빨간 글씨는 혼내는 게 아니라 어디가 문제인지 알려주는 신호입니다. 그대로 복사해서 클로드한테 붙여넣고 물어보면 원인 찾아 고쳐줍니다. 코드를 못 읽어도 됩니다.

🍽 식당에선 주방 경고등입니다. 불이 들어왔다고 가게가 망한 게 아니라, 어디를 보라는 뜻이죠.
클로드한테 이렇게 하세요
  • 빨간 글씨 전체를 그대로 복사
  • 클로드 채팅에 붙여넣기
  • "이거 왜 이래? 고쳐줘"
요약만 붙여넣지 마세요. 빨간 글씨를 통째로 줘야 정확히 짚습니다. 길어도 상관없습니다.
07

에이피아이 키

API Key

유료 서비스를 쓸 수 있는 비밀 열쇠입니다. 이걸 코드에 그냥 적어두고 공개하면, 남이 훔쳐서 내 돈으로 씁니다. 요금 폭탄이 이렇게 옵니다.

🍽 식당에선 금고 열쇠입니다. 코드에 적어두는 건 열쇠를 가게 문에 테이프로 붙여두는 것과 같아요.
클로드한테 이렇게 말하세요
  • 키를 금고에 숨겨줘
  • 코드에선 불러 쓰게 해줘
  • 공개하기 전에 키 빠졌는지 확인해줘
여기만은 대충 넘기지 마세요. 여덟 개 중에 실제로 돈이 나가는 건 이거 하나입니다.
08

인증

Auth

누가 누군지 확인하는 것, 쉽게 말해 로그인입니다. 이게 없으면 아무나 들어와서 남의 정보를 봅니다. 실제로 노코드로 만든 앱에서 자주 터지는 사고예요.

🍽 식당에선 번호표입니다. 번호 확인 없이 음식을 내주면 남이 내 몫을 가져갑니다.
클로드한테 이렇게 말하세요
  • 로그인 붙여줘
  • 내가 쓴 것만 나한테 보이게 해줘
  • 로그인 안 한 사람은 못 들어오게 막아줘
ORDER

만들 때는 이 순서입니다

여덟 개를 다 알 필요는 없고, 필요할 때마다 하나씩 꺼내 쓰면 됩니다. 실제로는 이 순서로 만납니다.

순서할 일쓰는 용어
1내 컴퓨터에서 앱 만들기에러, 깃
2정보 쌓을 곳 만들기DB
3어려운 기능 갖다 붙이기API, API 키
4아무나 못 들어오게 막기인증
5인터넷에 올리기배포, 서버
깃은 1번부터 켜두세요. 나중에 켜면 그전 기록이 없어서 못 되돌립니다. 제일 먼저 시켜야 하는 게 이겁니다.
START

터미널에 붙여넣기

cd my-app

클로드가 켜지면 이걸 붙여넣으세요. 위에서 본 여덟 개를 순서대로 챙겨주는 프롬프트입니다.

첫 프롬프트
나는 코딩을 모르는 사람이야. 간단한 웹앱을 하나 만들 건데,
용어를 몰라도 따라갈 수 있게 네가 순서를 잡아줘.

만들고 싶은 것: (여기에 한 줄로 쓰세요. 예: 우리 가족 할 일 목록)

【지켜줄 것】
1. 제일 먼저 깃을 켜줘. 매 단계 끝날 때마다 저장해줘.
   내가 망쳐도 되돌릴 수 있게.
2. 정보를 쌓아야 하면 DB를 붙여줘. 뭘 쓰는지 한 줄로 알려줘.
3. 결제나 지도처럼 어려운 건 직접 만들지 말고 갖다 붙여줘.
4. 비밀 열쇠(API 키)가 생기면 코드에 적지 말고 금고에 숨겨줘.
   공개하기 전에 키가 빠졌는지 꼭 확인해줘.
5. 로그인이 필요하면 붙이고, 내가 쓴 건 나만 보이게 해줘.
6. 다 되면 인터넷에 배포하고 접속 링크를 줘.

【말하는 법】
전문 용어를 쓸 때마다 괄호로 쉬운 말을 같이 적어줘.
예: 배포(인터넷에 올려서 남들이 볼 수 있게 하는 것)

에러가 나면 나한테 빨간 글씨를 그대로 보여주고,
왜 그런지 한 줄로 설명한 다음 고쳐줘.

한 단계 끝날 때마다 "지금 뭐가 됐는지"를 한 줄로 알려줘.
