영상에서 말한 하나·둘·셋

1

켤 거면 새 대화에서 처음부터 켠다

대화 끝에서 켜면 그 대화 전체를 다시 삽니다. /clear 로 새로 열고 첫 턴 전에 /fast. 공식 문서도 "enable fast mode at the start of a session" 을 권합니다.

2

크레딧 켜기 전에 월 한도부터 건다

claude.ai Settings › Usage › Usage credits 에서 켜고 끄고, monthly spend limit 을 정합니다. 클로드 코드에서 /usage-credits 를 치면 그 페이지가 열려요. 크레딧이 켜져 있으면 구독 한도를 다 쓴 뒤에도 크레딧으로 계속 과금될 수 있으니 한도부터.

3

대화마다 다시 켜게 설정 한 줄

기본값은 한 번 켜면 다음 세션도 켜진 채 시작합니다. 아래 한 줄을 ~/.claude/settings.json 에 넣으면 세션마다 꺼진 채 시작하고 필요할 때만 /fast 로 켭니다.

~/.claude/settings.json
{
  "fastModePerSessionOptIn": true
}

지금 확인하는 법

클로드 코드에서 /fast 를 한 번 쳐보세요. Fast mode requires usage credits 가 뜨면 크레딧이 꺼져 있는 것이고, 패스트 모드로 나간 돈은 아직 없습니다. 대신 Fast mode ON 이 뜨면 이미 크레딧으로 과금 중이니 /fast 를 다시 쳐서 끄고 Settings › Usage 에서 이번 달 지출을 확인하세요.

내 대화 크기를 세는 스크립트

클로드 코드가 남긴 대화 기록에서 세션별 최대 컨텍스트를 찍습니다

이렇게 하세요

  1. 아무 폴더에 ctx_sizes.js 로 저장합니다. 맨 위 dir 의 프로젝트 폴더 이름만 내 것으로 바꿉니다(~/.claude/projects/ 안에 있어요).
  2. 터미널에서 node ctx_sizes.js 를 칩니다. 설치할 것 없고, 어디로도 보내지 않습니다.
  3. 첫 행이 가장 긴 대화입니다. 그 토큰 수를 위 계산기에 넣으면 끝.
ctx_sizes.js
#!/usr/bin/env node
// 내 클로드 코드 세션들의 컨텍스트 크기(토큰) , 트랜스크립트(~/.claude/projects/<프로젝트>/*.jsonl)의
// 각 요청 usage(input + cache_read + cache_creation)를 읽어 세션별 최대값을 찍는다. 화면 수치의 근거(reel_fastlimit).
// 실행: node ctx_sizes.js [--fast 10]   (--fast: 패스트 모드 입력 단가 $/MTok, 켜는 순간 = 컨텍스트 x 단가)
const fs = require("fs"), path = require("path"), os = require("os");
const dir = path.join(os.homedir(), ".claude/projects/-home-user-template");
const RATE = Number((process.argv.indexOf("--fast") > -1 && process.argv[process.argv.indexOf("--fast") + 1]) || 10);
const rows = [];
for (const f of fs.readdirSync(dir).filter(f => f.endsWith(".jsonl"))) {
  let peak = 0, n = 0;
  for (const line of fs.readFileSync(path.join(dir, f), "utf8").split("\n")) {
    if (!line.includes('"usage"')) continue;
    let j; try { j = JSON.parse(line); } catch { continue; }
    const u = j.message && j.message.usage; if (!u) continue;
    const ctx = (u.input_tokens || 0) + (u.cache_read_input_tokens || 0) + (u.cache_creation_input_tokens || 0);
    n++; if (ctx > peak) peak = ctx;
  }
  if (n) rows.push({ id: f.slice(0, 8), n, peak });
}
rows.sort((a, b) => b.peak - a.peak);
console.log("세션      요청수   최대 컨텍스트(토큰)   /fast 켜는 순간($" + RATE + "/MTok)");
for (const r of rows.slice(0, 12)) console.log(`${r.id}  ${String(r.n).padStart(6)}   ${r.peak.toLocaleString("en-US").padStart(16)}   $${(r.peak * RATE / 1e6).toFixed(2)}`);
console.log(`세션 ${rows.length}개 · 최대 ${rows[0].peak.toLocaleString("en-US")} 토큰 → $${(rows[0].peak * RATE / 1e6).toFixed(2)}`);
숫자 출처: /fast 화면·/usage 화면은 제 Max 계정 클로드 코드 실화면(2026-09-16), 토큰 수는 위 스크립트 실행값, 단가는 Anthropic 공식 문서. 실제로 크레딧을 켜서 결제한 값은 없습니다.
