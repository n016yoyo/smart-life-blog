「모니터 받침대」로 받아온 질문 여덟 개 중 여섯이 이미 산 다음을 묻고 있었습니다. 제 글은 사기 전 이야기만 하고 있었고요.

먼저 알아야 할 것 , 키 받는 곳이 바뀌었습니다

예전에는 네이버 개발자센터에서 애플리케이션을 등록하면 검색 API 키가 나왔습니다. 지금은 안 됩니다. 2026년 9월 기준 등록 화면의 「사용 API」 목록에 검색이 아예 없습니다 (네이버 로그인 · 인증서 · 전자문서 · 네이버페이 배송지 · 카페 · 캘린더 · 캡차 2종, 이렇게 여덟 개뿐). 억지로 넣으면 서버가 신규로 등록할 수 없는 API가 선택되었습니다 라고 답합니다.

지금 열려 있는 길은 네이버 클라우드(NCP)의 NAVER API HUB 하나입니다. 검색 API는 하루 25,000회까지 무료이고, 그 안에서 쓰면 요금이 0원입니다. 다만 NCP 가입에는 본인인증과 결제수단 등록이 필요합니다. 카드 등록 없이는 콘솔이 열리지 않습니다.

★NCP에서 API HUB 말고는 아무것도 켜지 마세요. 서버(Compute) · DB · 스토리지 · CDN은 무료 상한이 없어서 켜는 순간부터 시간당 요금이 붙습니다. API HUB는 한도 입력 최대값이 무료 쿼터와 같아서 초과 설정 자체가 불가능합니다 , 그래서 안전합니다.

따라 하는 순서

키 두 개를 받고, 명령 한 줄을 칩니다

1

네이버 검색광고 API 키

월 검색수를 재는 데 씁니다. 무료입니다.

searchad.naver.com 로그인 → 우측 상단 도구 → API 사용 관리 → 「네이버 검색광고 API 서비스 신청」 → 액세스라이선스·비밀키·고객 ID 세 가지를 받습니다.

2

NAVER API HUB 키

지식iN 질문과 문서 수를 받는 데 씁니다. 검색 25,000회/일 무료.

ncloud.com 가입(본인인증·결제수단 등록) → 콘솔 → NAVER API HUB → Application 등록 → Client ID·Client Secret을 받습니다. 다른 상품은 켜지 마세요.

3

질문을 받아옵니다

키를 파일 두 개로 저장한 뒤 명령 한 줄이면 끝입니다.

키 저장
docs/scrape/.naver_searchad.json
{"apiKey":"...", "secretKey":"...", "customerId":"..."}

docs/scrape/.naver_apihub.json
{"clientId":"...", "clientSecret":"..."}
실행
node docs/naver-keyword/ask.js "모니터 받침대" --n 8
