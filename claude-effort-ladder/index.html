한 줄 요약

같은 로우폴리 호랑이 요청을 클로드 Opus 5.5 에 effort(생각 수준)만 low, medium, high, xhigh, max 로 바꿔 한 번씩 보냈습니다. 정가로 환산한 비용은 max 가 low 의 16.5배, 걸린 시간은 107.8배였고, 다섯 결과 모두 콘솔 오류 없이 재생됐습니다. xhigh 와 max 에는 요청에 없던 속도 슬라이더가 붙어 있었습니다.

각 단계 한 번씩 잰 값입니다. 같은 요청을 다시 보내면 값이 조금씩 다르게 나옵니다.

결과물에서 보이는 것만

좋고 나쁨의 평가는 하지 않고, 화면에 실제로 있는 것만 적었습니다

1

low · medium

low 는 상자 몸통에 풀 몇 포기, medium 은 꼬리가 휘고 바위가 생겼습니다.

2

high

바닥 무늬, 풀, 바위와 얼굴 무늬가 있습니다.

3

xhigh · max

둘 다 요청에 없던 속도 슬라이더와 일시정지 버튼이 붙어 있었습니다. xhigh 는 뒤에 나무도 있습니다. max 는 둥근 몸통이 보입니다.

직접 바꿔 보는 법, 셋

클로드 코드를 열면 바로 됩니다

1

/effort 치고 ←/→ 로 고르기

슬래시 effort 를 입력하면 low, medium, high, xhigh, max 가 놓인 슬라이더가 뜹니다. 좌우 화살표로 옮기고 Enter 로 확정합니다.

2

s 는 이 대화에서만

패널 아래 안내에 「s for this session only」가 있습니다. 제가 max 에서 s 를 눌러 보니 「Set effort level to max (this session only)」가 떴습니다.

3

첫 화면 맨 위에서 지금 값 확인

클로드 코드 첫 화면 머리 둘째 줄에 「Opus 5.5 with xhigh effort」처럼 지금 모델과 effort 가 적혀 있습니다.

max 를 고를 때 클로드 코드가 띄운 안내문 그대로

「Maximum capability with deepest reasoning. May use excessive tokens resulting in long response times or overthinking. Use sparingly for the hardest tasks.」

제 결과에서는 max 가 low 의 16.5배 비용, 107.8배 시간이었습니다. 그래서 저는 처음부터 max 로 시작하지 않고 low 로 먼저 돌려 보고, 결과가 모자라면 한 칸씩 올리려고 합니다. 이건 쉬운 요청 한 번으로 정한 제 방식이고, 어려운 일에서 어느 단계가 맞는지는 재 보지 않았습니다.

시간은 실행 기록 duration_ms(각 42,543 · 92,712 · 395,437 · 844,398 · 4,580,365). 비용은 실행 기록 total_cost_usd 를 API 정가로 환산한 세션 전체 값이라 단계마다 고정으로 들어가는 입력 토큰(캐시에 쓰는 약 8만 토큰)이 포함돼 있습니다. 나중에 같은 low 요청을 클로드 앱 커넥터를 끄고(--strict-mcp-config) 다섯 번 다시 돌렸더니 캐시 쓰기는 약 6천 토큰, 정가 환산은 $0.125~$0.138 이었습니다. 이 표는 그 플래그 없이 기본 구성으로 잰 값이라 그 고정 비용이 들어 있고, 단계 사이 배수는 그 고정 비용을 뺀 값이 아닙니다. 정확한 원인은 가려내지 못했습니다. 배수는 같은 표의 두 칸을 나눈 값입니다: 비용 12.4162 ÷ 0.75135 = 16.5배, 시간은 표에 적은 값으로 4,580.4 ÷ 42.5 = 107.8배(ms 원값 4,580,365 ÷ 42,543 으로 나누면 107.7배). 재생 오류는 헤드리스 크롬에서 16초 틀며 예외와 콘솔 오류를 센 값입니다.

알아 둘 것

단계마다 한 번씩만 돌렸고, 그때그때 캐시 상태도 달랐습니다. 다시 돌리면 값이 달라질 수 있습니다.

비용은 API 정가 환산입니다. 구독이면 따로 청구되지 않고 한도에서 나가는데, 이 실험이 한도를 몇 % 썼는지는 재지 않았습니다.

실험 다섯 번은 Claude Code v2.1.280 으로 돌렸고, /effort 패널과 첫 화면 캡처는 v2.1.285 입니다. 패널의 Ultracode 스위치는 돌려 보지 않았습니다.
