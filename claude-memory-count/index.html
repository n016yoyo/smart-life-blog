왜 세어봤냐면

새 대화를 열고 "내가 뭘 좋아하냐"고 물었습니다. 좋아하는 음식은 기록에 없어서 모른다더니, 제 취향은 다섯 개를 줄줄 대더라고요. 엠대시 쓰지 마라, 촌스러운 거 싫어한다, 낯선 효과음 싫어한다까지요. 어디서 나온 건지 찾아보니 제 컴퓨터 안에 파일로 있었습니다.

※ 아래 숫자는 제 컴퓨터의 2026년 9월 6일 값입니다. 여러분 것은 쓴 만큼 다릅니다. 오늘 깐 분은 0개가 나올 수도 있고, 그것도 맞는 결과예요.

남는 자리는 세 군데

내 컴퓨터 안에서만 따졌을 때입니다

1

지금 이 창에 떠 있는 대화

새 대화를 열고 앞 대화를 물어봤더니 "이 세션은 새로 시작된 것이라 앞 대화 내용이 남아 있지 않습니다"라고 답했습니다. 창을 닫으면 다음 대화는 이걸 못 읽어요.

2

메모리 파일 233개

이건 새 대화에도 따라옵니다. 그래서 제 취향을 답할 수 있었던 거예요. 종류를 세어보니 피드백 137개, 레퍼런스 60개, 프로젝트 35개, 미분류 1개였습니다.

3

대화 기록 379개

29일치가 통째로 폴더에 남아 있었습니다. 0.35GB 예요. 대화창을 닫아도 파일은 그대로입니다.

내 것 세는 명령

터미널에 그대로 붙여넣으면 됩니다

① 메모리 파일이 몇 개인가
ls ~/.claude/projects/*/memory/*.md 2>/dev/null | grep -v "MEMORY" | wc -l
② 종류별로 몇 개인가
grep -h "^  type:" ~/.claude/projects/*/memory/*.md 2>/dev/null | sort | uniq -c | sort -rn
③ 대화 기록이 몇 개인가
ls ~/.claude/projects/*/*.jsonl 2>/dev/null | wc -l
④ 언제부터 쌓였나
ls -lt ~/.claude/projects/*/*.jsonl 2>/dev/null | tail -1

뭐가 들었는지 직접 열어보기

  1. 목록만 보기 , ls ~/.claude/projects/*/memory/
  2. 한 개 열어보기 , cat ~/.claude/projects/*/memory/<파일이름>.md
  3. 파일 맨 위 type: 이 종류입니다(feedback = 내가 고쳐준 것, reference = 도구·경로, project = 진행 중인 일)

지우기 전에 이것만

지우면 클로드가 그만큼 다시 물어봅니다. 확인하며 지우려면 rm -i 를 쓰세요. 통째로 지우는 명령은 되돌릴 수 없으니, 먼저 ls 로 목록을 보고 필요 없는 것만 고르시는 걸 권합니다.

이 페이지 숫자의 출처 , 전부 제 컴퓨터에서 위 명령으로 잰 값입니다(2026-09-06). 메모리는 memory 폴더의 .md 파일 수에서 색인·아카이브를 뺀 것, 종류는 파일 앞머리 type 값, 대화 기록은 projects 폴더의 세션 파일 수입니다. 릴스 화면에 나온 터미널은 이 명령을 실제로 돌린 화면 그대로입니다.
