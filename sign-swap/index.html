영상 속 간판 글자만 갈아끼우기

카메라가 움직이는 영상에서 전광판·간판의 글자만 바꿉니다. 판은 그대로 있고 글자만 내 것이 됩니다. 붙여넣기용 코드 전문과, 세 번 실패하고 찾은 방법까지.

코드 전문 공개 유료 툴 불필요 9초 영상 약 3분
👀 지금까지 … 명이 봤어요
뭐가 되는 건가 핵심 아이디어 준비물 코드 전문 돌려보기 함정 다섯 남은 한계
WHY

뭐가 되는 건가

길거리를 찍은 영상에 간판이 하나 있다고 해봅시다. 카메라는 움직이고, 간판은 화면 안에서 위치도 각도도 계속 바뀝니다. 그 간판의 글자만 내가 원하는 문구로 바꿉니다. 판의 색도, 기울기도, 카메라 흔들림도 그대로입니다.

영상 편집 프로그램의 모션 트래킹으로도 되지만, 구간마다 손으로 키프레임을 잡아야 합니다. 여기서는 명령 한 줄로 끝까지 자동입니다. 9초짜리 세로 영상(218프레임) 기준으로 합성부터 인코딩까지 약 3분 걸렸습니다.

파이썬을 못 써도 됩니다. 아래 코드는 클로드 코드에게 그대로 저장시키고 명령만 치면 됩니다. 필요한 것(OpenCV 등)도 클로드가 설치합니다. 이 글은 "클로드한테 뭐라고 시키면 되는지"를 정리한 것입니다.
IDEA

핵심 아이디어 한 줄

색으로 찾는 건 첫 프레임 딱 한 번, 그 뒤로는 같은 점을 따라간다

간판이 노란색이면 "노란 영역을 찾아라"로 쉽게 잡힙니다. 그런데 이걸 매 프레임 다시 하면, 빛과 그림자 때문에 꼭짓점이 매번 몇 픽셀씩 달라집니다. 결과물에서 판이 덜덜 떱니다.

그래서 첫 프레임에서만 색으로 찾고, 그 다음부터는 Optical Flow(그 픽셀 뭉치가 다음 프레임에서 어디로 갔는지 추적하는 방법)로 같은 점을 따라갑니다. 떨림이 사라집니다.

전체 흐름은 여섯 단계입니다.

  1. 첫 프레임에서 색으로 판의 네 꼭짓점을 찾는다
  2. 추적점 9개(꼭짓점 4 + 변 중점 4 + 중심 1)를 프레임마다 따라간다
  3. 3프레임 이동평균으로 미세 떨림만 없앤다
  4. 갈아끼울 글자판 이미지를 만든다(배경색은 원본 그대로)
  5. 그 이미지를 판의 기울기에 맞춰 찌그러뜨려 얹는다
  6. 경계를 흐려서 합성 티를 없애고 인코딩한다

① 글자판 만들기 make_board_text.py

원본 간판과 같은 배경색에 새 문구를 얹은 PNG를 만듭니다. 글자 크기는 판 폭에 맞춰 자동으로 계산합니다.

make_board_text.py
import sys, os
from PIL import Image, ImageDraw, ImageFont

OUT, Wt, Ht = sys.argv[1], int(sys.argv[2]), int(sys.argv[3])
LINES = sys.argv[4:]
BG   = os.environ.get("BOARD_BG", "#FFD400")
FONT = os.environ.get("BOARD_FONT", "/home/user/.fonts/GothicA1-EB.ttf")
INK  = "#141414"

img = Image.new("RGBA", (Wt, Ht), BG)
dr  = ImageDraw.Draw(img)

# 줄 문법: "텍스트"  |  "텍스트|색:크기배율"  |  "앞:색+뒤:색"
parsed = []
for raw in LINES:
    scale, body = 1.0, raw
    if "|" in raw:
        body, meta = raw.split("|", 1)
        if ":" in meta:
            col, sc = meta.split(":", 1); scale = float(sc)
        else:
            col = meta
        parsed.append(([(body, "#" + col.lstrip("#"))], scale)); continue
    chunks = []
    for part in body.split("+"):
        if ":" in part:
            t, c = part.split(":", 1); chunks.append((t, "#" + c.lstrip("#")))
        else:
            chunks.append((part, INK))
    parsed.append((chunks, scale))

# 제일 긴 줄이 폭의 86% 를 채우도록 폰트 크기를 이분 탐색
PADX = Wt * 0.07
def line_w(chunks, f): return sum(dr.textlength(t, font=f) for t, _ in chunks)
lo, hi = 10, Ht
while lo < hi:
    mid = (lo + hi + 1) // 2
    widest  = max(line_w(c, ImageFont.truetype(FONT, int(mid * s))) for c, s in parsed)
    tallest = sum(int(mid * s) * 1.22 for _, s in parsed)
    if widest <= Wt - PADX * 2 and tallest <= Ht * 0.86: lo = mid
    else: hi = mid - 1
base = lo

heights = [int(base * s) * 1.22 for _, s in parsed]
y = (Ht - sum(heights)) / 2
for (chunks, s), h in zip(parsed, heights):
    f = ImageFont.truetype(FONT, int(base * s))
    x = (Wt - line_w(chunks, f)) / 2
    for t, c in chunks:
        dr.text((x, y), t, font=f, fill=c); x += dr.textlength(t, font=f)
    y += h

img.save(OUT)
print(f"글자판 {Wt}x{Ht} · 폰트 {base}px · {len(parsed)}줄 → {OUT}")

② 영상에 붙이기 board_swap.py

판을 찾고, 따라가고, 찌그러뜨려 얹고, 인코딩까지 한 번에 합니다.

board_swap.py
import cv2, numpy as np, sys, os, subprocess, tempfile

args  = [a for a in sys.argv[1:] if not a.startswith("--")]
flags = [a for a in sys.argv[1:] if a.startswith("--")]
INP, PNG, OUT = args[0], args[1], args[2]
PREVIEW = "--preview" in flags
hsv_arg = next((f.split("=",1)[1] for f in flags if f.startswith("--hsv=")), "18,40,120,170")
HL, HH, SMIN, VMIN = [int(x) for x in hsv_arg.split(",")]

cap = cv2.VideoCapture(INP)
fps = cap.get(cv2.CAP_PROP_FPS) or 24
ok, f0 = cap.read()
if not ok: sys.exit("프레임 없음")
H, W = f0.shape[:2]

# ① 첫 프레임에서만 색으로 판 찾기
hsv  = cv2.cvtColor(f0, cv2.COLOR_BGR2HSV)
mask = cv2.inRange(hsv, np.array([HL,SMIN,VMIN]), np.array([HH,255,255]))
mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, np.ones((9,9), np.uint8))
cnts, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
if not cnts: sys.exit("그 색 영역을 못 찾았다 , --hsv 로 범위를 넓혀라")
c  = max(cnts, key=cv2.contourArea)
ap = cv2.approxPolyDP(c, 0.02 * cv2.arcLength(c, True), True)
quad = (ap.reshape(4,2) if len(ap) == 4 else cv2.boxPoints(cv2.minAreaRect(c))).astype(np.float32)
s, d = quad.sum(1), np.diff(quad, axis=1).ravel()
quad = np.float32([quad[np.argmin(s)], quad[np.argmin(d)], quad[np.argmax(s)], quad[np.argmax(d)]])
print("판 꼭짓점:", " ".join(f"({int(x)},{int(y)})" for x,y in quad))

if PREVIEW:                                   # 검출만 확인하고 끝내는 모드
    vis = f0.copy(); cv2.polylines(vis, [quad.astype(int)], True, (0,0,255), 4)
    for i,(x,y) in enumerate(quad):
        cv2.circle(vis, (int(x),int(y)), 12, (0,255,255), -1)
        cv2.putText(vis, str(i), (int(x)+16,int(y)), cv2.FONT_HERSHEY_SIMPLEX, 1.4, (0,0,255), 3)
    cv2.imwrite(OUT, vis); sys.exit(0)

# ② 추적점 9개 = 꼭짓점4 + 변 중점4 + 중심1
def nine(q):
    mid = [(q[i] + q[(i+1)%4]) / 2 for i in range(4)]
    return np.float32(list(q) + mid + [q.mean(0)]).reshape(-1,1,2)

pts = nine(quad)
prev_gray = cv2.cvtColor(f0, cv2.COLOR_BGR2GRAY)
LK = dict(winSize=(31,31), maxLevel=4,
          criteria=(cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_COUNT, 30, 0.01))

txt = cv2.imread(PNG, cv2.IMREAD_UNCHANGED)
if txt.shape[2] == 3:
    txt = np.dstack([txt, np.full(txt.shape[:2], 255, np.uint8)])
th, tw = txt.shape[:2]
src_quad = np.float32([[0,0],[tw,0],[tw,th],[0,th]])

tmp = tempfile.mkdtemp(prefix="boardswap_")
hist, n = [], 0
while True:
    if n > 0:
        ok, frame = cap.read()
        if not ok: break
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        nxt, st, _  = cv2.calcOpticalFlowPyrLK(prev_gray, gray, pts, None, **LK)
        back, _, _  = cv2.calcOpticalFlowPyrLK(gray, prev_gray, nxt, None, **LK)
        good = (np.linalg.norm(pts - back, axis=2).ravel() < 2.0) & (st.ravel() == 1)
        upd = nxt.copy(); upd[~good] = pts[~good]
        pts, prev_gray = upd, gray
    else:
        frame = f0
    q = pts[:4].reshape(4,2).copy()
    hist.append(q)
    if len(hist) > 3: hist.pop(0)                       # ③ 3프레임 이동평균
    qs = np.mean(hist, axis=0).astype(np.float32)

    M = cv2.getPerspectiveTransform(src_quad, qs)        # ⑤ 기울기에 맞춰 찌그러뜨리기
    warped = cv2.warpPerspective(txt, M, (W,H), flags=cv2.INTER_LANCZOS4,
                 borderMode=cv2.BORDER_CONSTANT, borderValue=(0,0,0,0))
    a = warped[:,:,3].astype(np.float32) / 255.0         # ⑥ 경계 페더
    a = cv2.erode(a, np.ones((5,5), np.uint8))
    a = cv2.GaussianBlur(a, (7,7), 0)[:,:,None]
    out = (warped[:,:,:3].astype(np.float32)*a + frame.astype(np.float32)*(1-a)).astype(np.uint8)
    cv2.imwrite(f"{tmp}/f{n:05d}.png", out); n += 1
cap.release()
print(f"합성 {n}프레임 → 인코딩")

subprocess.run(["ffmpeg","-loglevel","error","-y","-framerate",str(fps),
  "-i",f"{tmp}/f%05d.png","-i",INP,"-map","0:v","-map","1:a?",
  "-c:v","libx264","-crf","18","-preset","medium","-pix_fmt","yuv420p",
  "-c:a","copy","-shortest",OUT], check=True)
print("✅", OUT, os.path.getsize(OUT)//1024, "KB")

TRAPS

함정 다섯

1. 매 프레임 색으로 찾으면 판이 떤다

제일 먼저 떠오르는 방법이고, 제일 먼저 실패합니다. 빛이 조금만 달라져도 꼭짓점이 몇 픽셀씩 튀어서 결과물에서 판이 덜덜 떨립니다. 이동평균을 7프레임까지 늘려도 티가 남았습니다. 첫 프레임만 색으로 찾고 나머지는 추적으로 바꾸고 나서야 안정됐습니다.

2. 추적점을 꼭짓점 4개만 쓰면 한 번 놓칠 때 통째로 튄다

사람이 판 앞을 지나가거나 판 모서리가 다른 물체에 가리면 그 점이 엉뚱한 데로 갑니다. 꼭짓점만 있으면 판 전체가 끌려갑니다. 변 중점 4개와 중심 1개를 더해 9개로 잡으면 하나가 흔들려도 나머지가 붙잡아 줍니다.

3. 되돌아가서 확인하지 않으면 추적이 조용히 어긋난다

Optical Flow 는 "못 찾았다"고 말해주지 않습니다. 엉뚱한 점을 찾아놓고 성공했다고 합니다. 그래서 다음 프레임으로 갔다가 다시 돌아와서 원래 자리에 오는지 봅니다(코드의 back 부분). 2픽셀 넘게 어긋나면 그 점은 버리고 이전 위치를 씁니다. 이게 없으면 사람이 지나갈 때 판이 사람을 따라갑니다.

4. 스무딩을 길게 걸면 카메라를 못 따라간다

떨림을 없애려고 이동평균을 길게 잡으면, 이번엔 카메라가 움직일 때 판이 한 박자 늦게 따라옵니다. 미끄러지는 것처럼 보입니다. 3프레임이면 미세 떨림만 없어지고 움직임은 그대로 따라갑니다.

5. 오디오를 다시 인코딩하면 싱크가 밀린다

합성한 이미지들을 영상으로 묶을 때 오디오까지 새로 인코딩하면 길이가 미세하게 달라져 입모양이 어긋납니다. -c:a copy 로 원본 오디오를 그대로 복사하세요. 코드에 그렇게 들어 있습니다.

무엇왜 티가 나나고치려면
LED 도트실제 전광판은 픽셀 격자가 보이는데 합성 글자는 매끈합니다글자판 위에 격자 패턴을 곱하기로 얹는다
모션 블러카메라가 빠르게 움직이면 원본은 살짝 뭉개지는데 합성 부분만 선명합니다직전 프레임 위치와 평균 내어 한 번 더 얹는다
노이즈원본에는 센서 노이즈가 깔려 있는데 합성 영역만 깨끗합니다합성 영역에만 같은 세기의 노이즈를 더한다
그리고 이건 기술 얘기가 아니라 예의 얘기인데요. 이 방법은 남의 영상 간판을 내 것으로 바꾸는 데에도 그대로 쓸 수 있습니다. 연습으로 해보는 것과 그걸 내 콘텐츠라고 올리는 것은 다른 일입니다. 남이 찍은 영상을 쓸 거면 출처를 밝히고, 그 사람 계정이 있던 자리에 내 계정을 얹어 올리는 일은 하지 마세요.
