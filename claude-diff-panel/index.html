클로드가 방금 뭘 고쳤는지
클로드 안에서 보는 법

git diff 로는 안 보이는 파일이 있습니다
필요한 것 업데이트 하나명령 /diff버전 2.1.260

왜 이걸 씁니까

AI 한테 일을 시키면 파일이 여러 개 바뀝니다. 그런데 무엇이 바뀌었는지 확인하려고 터미널에서 git diff 를 치면, 새로 만든 파일은 한 줄도 안 나옵니다. 깃은 아직 추적하지 않는 파일을 diff 대상으로 보지 않기 때문입니다.

저희가 실제로 재봤습니다. 같은 저장소 같은 상태에서 git diff 는 1개, /diff 패널은 4개였고, 차이인 3개는 전부 클로드가 새로 만든 파일이었습니다.

이렇게 씁니다

클로드 코드 안에서 명령 한 줄

클로드 안에서 그대로 치세요
/diff

패널 조작

  1. /diff 를 치면 바뀐 파일 목록이 열립니다. 맨 위에 N files changed +N -N 이 뜹니다.
  2. ↑ ↓ 로 파일을 고릅니다. 목록이 길면 alt+↓ 로 넘깁니다.
  3. Enter 를 치면 그 파일의 바뀐 줄이 그 자리에서 열립니다. 빨간 줄이 지운 것, 초록 줄이 넣은 것입니다.
  4. 파일 안에서도 ↑ ↓ 로 스크롤하고, Esc 로 목록으로 돌아옵니다. 한 번 더 Esc 를 치면 패널이 닫힙니다.
  5. 새로 만든 파일에는 untracked 라고 붙습니다. 아직 깃에 올리지 않았다는 뜻이라 줄 수는 안 세어집니다.

git diff 와 무엇이 다른가

같은 저장소, 같은 순간에 재본 것입니다

1

새로 만든 파일

git diff 는 안 보여줍니다. 패널은 untracked 라고 표시해서 보여줍니다. 저희 화면에서는 이 차이가 3개였습니다.

2

창을 옮길 필요

git diff 는 터미널 새 창이 필요합니다. 패널은 클로드 안에서 열리고 Esc 로 닫힙니다.

3

바뀐 줄 보기

패널에서는 파일을 고르고 Enter 한 번이면 그 자리에서 열립니다. 명령을 다시 칠 필요가 없습니다.

저희가 걸린 함정

새로 만든 파일은 "그 세션이 만든 것"만 뜹니다. 클로드를 새로 켜고 /diff 를 치면, 폴더에 untracked 파일이 있어도 목록에 안 나옵니다. 클로드가 그 세션에서 만든 파일이라야 잡힙니다. 그래서 일을 시킨 그 창에서 바로 확인하는 게 맞습니다.

그리고 패널이 열려 있는 동안에는 프롬프트를 칠 수 없습니다. 키가 패널 조작으로 들어갑니다. 먼저 Esc 로 닫고 이어서 시키세요.

안 되면 업데이트부터

  1. 패널은 2.1.260 에서 확인했습니다. 클로드를 켰을 때 맨 위에 버전이 찍힙니다.
  2. 낮으면 터미널에서 npm i -g @anthropic-ai/claude-code 를 한 번 돌리고 클로드를 다시 켜세요.
  3. 다시 켜면 Updated to latest. 줄이 뜨고, 그다음부터 /diff 가 목록에 보입니다.
이 페이지의 수치는 저희 저장소에서 실제로 잰 값입니다. git diff --stat HEAD 는 1 file changed, 1 insertion(+), 같은 상태에서 /diff 패널은 4 files changed +1 이었고 그중 3개가 untracked 였습니다. 화면은 전부 실제 캡처입니다.
