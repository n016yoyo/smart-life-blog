직접 재보는 법

제가 돌린 러너 그대로

이렇게 했습니다

  1. 빈 폴더에 과제 프롬프트를 task.txt 로 둡니다(제 것: 재입고 알림 폼 · 블로그 제목 날짜 추출 · 조회수 "1.2만" 파싱 버그 수정).
  2. 아래 러너가 없이 · 포니테일 · 케이브맨 · 둘 다 네 폴더에서 같은 프롬프트를 claude -p --output-format json 으로 돌립니다. --setting-sources "" 로 내 CLAUDE.md·메모리를 끊어야 공정합니다.
  3. 결과 JSON 의 usage · total_cost_usd · duration_ms · num_turns 를 읽고, 코드 줄은 wc -l.
  4. 품질은 에이전트가 못 본 테스트로. 폼이면 브라우저에서 실제로 눌러봅니다(제 것은 playwright 11항목).
run_arms.sh
#!/bin/bash
# usage: run_arms.sh <taskdir>   (needs <taskdir>/task.txt, optional <taskdir>/seed/ copied into each arm)
set -u
D=$(cd "$1" && pwd); T=$(cat "$D/task.txt")
PONY=$HOME/plugins/ponytail; CAVE=$HOME/plugins/caveman
declare -A PL=( [base]="" [pony]="--plugin-dir $PONY" [cave]="--plugin-dir $CAVE" [both]="--plugin-dir $PONY --plugin-dir $CAVE" )
for a in base pony cave both; do
  rm -rf "$D/$a"; mkdir -p "$D/$a"; [ -d "$D/seed" ] && cp -r "$D/seed/." "$D/$a/"
  ( cd "$D/$a" && claude -p --model claude-fable-5-1 --setting-sources "" --permission-mode acceptEdits ${PL[$a]} --output-format json "$T" > "$D/$a.json" 2> "$D/$a.err" < /dev/null; echo "$a exit $?" ) &
done
wait
