KEY

준비물: 파트너스 API 키

쿠팡 파트너스에 가입한 뒤 파트너스 사이트 에서 Open API 액세스 키와 시크릿 키를 발급받습니다. 두 키는 코드에 적지 말고 파일로 두고 권한을 600 으로 잠급니다.

COUPANG_ACCESS_KEY=발급받은키
COUPANG_SECRET_KEY=발급받은시크릿

서명은 HmacSHA256 이고, 서명 문자열은 yymmddTHHMMSSZ + METHOD + PATH + QUERY 입니다. 이 순서가 틀리면 401 이 납니다.

솔직한 부분
