AI TIGER MASK

품절템 재입고, 폰이 먼저 알게 하기

웹페이지를 대신 지켜보다가 "품절" 두 글자가 사라지는 순간 폰으로 알려줍니다. 예약 오픈, 가격 떨어짐, 티켓 풀림에도 그대로 씁니다. 개발 몰라도 됩니다.

WHY

뭐가 되는 건가

사고 싶은 게 품절이면 하루에도 몇 번씩 들어가 보게 됩니다. 그러다 잠깐 안 본 사이에 풀렸다가 다시 닫히면, 또 몇 달을 기다립니다.

이 도구는 그 페이지를 대신 봅니다. 기본 5분마다 한 번씩 열어보고, "품절"이라는 글자가 사라지면 그 순간 폰으로 텔레그램 메시지를 보냅니다. 컴퓨터를 켜두기만 하면 자는 동안에도 봅니다.

"품절"만 되는 게 아닙니다. 웹페이지에 글자로 뜨는 것이면 다 됩니다. 반대로 "예약하기"가 생기면 알림받는 것도 됩니다(오픈 감시). 가격표, 티켓 잔여석, 공지 게시, 배송 상태 , 화면에 글자가 바뀌는 건 전부 대상입니다.

개발을 몰라도 됩니다. 아래 코드 두 개를 클로드 코드에게 그대로 저장시키고 명령만 치면 됩니다. Node.js 설치도 클로드가 해줍니다. 이 글은 "클로드한테 뭐라고 시키면 되는지"를 정리한 것입니다.
PREP

준비물 , 두 개뿐입니다

무엇왜 필요한가
텔레그램알림을 받는 곳입니다. 폰에 깔려 있으면 됩니다. 카카오톡은 개인이 봇으로 메시지를 보내는 길이 막혀 있어서 텔레그램을 씁니다
Node.js코드를 돌리는 프로그램입니다. 없으면 nodejs.org 에서 LTS 를 받으세요. 클로드에게 "노드 깔아줘"라고 해도 됩니다

계정 가입도, 결제도, API 키 구매도 없습니다. 텔레그램 봇은 공짜입니다.

STEP 1

알림 보낼 봇 만들기 , 3분, 한 번만

텔레그램에서 "봇"은 내가 만든 프로그램이 나에게 말을 걸 수 있게 해주는 창구입니다. 만드는 것도 텔레그램 안에서 합니다.

1

텔레그램에서 @BotFather 를 검색해 대화를 엽니다

파란 체크가 붙은 공식 계정입니다. 봇을 만들어주는 봇입니다.

2

/newbot 이라고 보냅니다

"새 봇을 만들자, 이름을 뭐라고 할까?"라고 되묻습니다.

3

이름을 두 번 정해줍니다

첫 번째는 표시 이름(아무거나), 두 번째는 아이디입니다. 아이디는 반드시 _bot 으로 끝나야 합니다. 이미 쓰는 이름이면 다시 물어봅니다.

4

긴 문자열을 하나 줍니다. 그게 토큰입니다

1234567890:AAH-xxxxxxxxxxxxxxxxxxxxxxxxxxxx 이렇게 생겼습니다. 복사해 두세요. 이건 비밀번호입니다. 남에게 보이면 그 사람이 내 봇을 조종할 수 있습니다.

5

★방금 만든 내 봇을 찾아서 아무 말이나 한 번 보냅니다

여기서 제일 많이 막힙니다. 텔레그램은 봇이 먼저 말을 걸 수 없게 막아둡니다(스팸 방지). 내가 먼저 한 마디 보내야 봇이 나를 알아봅니다. "안녕" 한 마디면 됩니다.

토큰이 남에게 노출됐다면 @BotFather 에게 /revoke 를 보내면 새 토큰이 발급되고 옛 토큰은 죽습니다. 봇 자체를 없애려면 /deletebot 입니다.
STEP 2

코드 전문 , 파일 두 개

폴더를 하나 만들고(tg-watch 같은 이름) 그 안에 아래 두 파일을 넣습니다. 클로드 코드를 쓰신다면 이 페이지를 그대로 붙여넣고 "이 두 파일 만들어줘"라고 하면 됩니다.

setup.js , 준비 확인 (한 번만 돌립니다)

토큰이 살아있는지 확인하고, 내 chat_id 를 자동으로 찾아서 저장합니다. chat_id 는 "누구에게 보낼지"를 가리키는 번호인데, 손으로 찾으려면 번거로워서 코드가 대신 찾게 했습니다.

setup.js
// 폰으로 알림 받을 준비 , 봇 토큰만 넣으면 나머지는 알아서.
//    사용: node setup.js <봇토큰>
const fs = require("fs"), path = require("path");
const CFG = path.join(__dirname, "config.json");
const token = (process.argv[2] || "").trim();

const api = async (m, q = "") => {
  const r = await fetch(`https://api.telegram.org/bot${token}/${m}${q}`);
  return r.json();
};

(async () => {
  if (!token) {
    console.log(`
폰으로 알림 받으려면 봇이 하나 필요합니다. 3분이면 됩니다.

  1) 텔레그램에서 @BotFather 를 찾아 대화를 엽니다
  2) /newbot 을 보내고, 이름을 두 번 정해줍니다(아무거나)
  3) 마지막에 알려주는 긴 문자열이 '토큰'입니다
  4) 방금 만든 내 봇을 찾아 아무 말이나 한 번 보냅니다  ← 이걸 안 하면 못 찾습니다
  5) 여기로 돌아와서:  node setup.js <토큰>
`);
    process.exit(0);
  }

  const me = await api("getMe");
  if (!me.ok) { console.log("❌ 토큰이 틀렸습니다. @BotFather 가 준 문자열을 그대로 붙여넣어 주세요."); process.exit(1); }
  console.log(`✅ 봇 확인: @${me.result.username}`);

  const up = await api("getUpdates", "?limit=10");
  const msg = (up.result || []).reverse().find(u => u.message && u.message.chat);
  if (!msg) {
    console.log(`
❌ 아직 대화가 없습니다.
   텔레그램에서 @${me.result.username} 을 찾아 **아무 말이나 한 번** 보내고 다시 실행해 주세요.
   (봇은 먼저 말을 건 사람에게만 보낼 수 있습니다)`);
    process.exit(1);
  }
  const chat = msg.message.chat;
  const chatId = chat.id;
  console.log(`✅ 받는 사람 확인: ${chat.first_name || chat.title || chatId}`);

  const send = await fetch(`https://api.telegram.org/bot${token}/sendMessage`, {
    method: "POST", headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ chat_id: chatId, text: "준비 끝났습니다. 이제 지켜보는 게 바뀌면 여기로 알려드릴게요." }),
  }).then(r => r.json());
  if (!send.ok) { console.log("❌ 메시지 전송 실패:", send.description); process.exit(1); }

  fs.writeFileSync(CFG, JSON.stringify({ token, chatId }, null, 1));
  fs.chmodSync(CFG, 0o600);
  console.log(`✅ 폰으로 테스트 메시지를 보냈습니다. 확인해 보세요.
   설정 저장: ${CFG}

다음: node watch.js "<지켜볼 주소>" "<사라지면 알림받을 말>"
   예)  node watch.js "https://example.com/product/123" "품절"`);
})();

watch.js , 지켜보다가 바뀌면 폰으로

주소를 열어서 태그를 걷어내고 사람 눈에 보이는 글자만 남깁니다. 그 안에 찾을 말이 있는지 없는지만 봅니다. 상태가 뒤집히면 보내고 끝냅니다.

watch.js
// 지켜보다가 바뀌면 폰으로 , 품절 재입고·예약 오픈·가격 변동에 그대로 쓴다.
//    사용: node watch.js "<주소>" "<찾을 말>" [분]
//      node watch.js "https://..." "품절"            , '품절'이 사라지면 알림(재입고)
//      node watch.js "https://..." "예약하기" --있으면 , '예약하기'가 생기면 알림(오픈)
//    기본 5분마다. ★남의 서버를 두드리는 일이라 1분 밑으로는 안 내려간다(차단당한다).
const fs = require("fs"), path = require("path");
const CFG = path.join(__dirname, "config.json");
if (!fs.existsSync(CFG)) { console.log("먼저: node setup.js <봇토큰>"); process.exit(1); }
const { token, chatId } = JSON.parse(fs.readFileSync(CFG, "utf8"));

const url = process.argv[2], needle = process.argv[3];
const onAppear = process.argv.includes("--있으면");
const mins = Math.max(1, parseInt(process.argv.find(a => /^\d+$/.test(a)) || "5"));
if (!url || !needle) { console.log('사용: node watch.js "<주소>" "<찾을 말>" [분] [--있으면]'); process.exit(1); }

const UA = "Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.0 Mobile/15E148 Safari/604.1";
const now = () => new Date(Date.now() + 9 * 3600e3).toISOString().slice(11, 19); // KST

const tg = async (text) => {
  const r = await fetch(`https://api.telegram.org/bot${token}/sendMessage`, {
    method: "POST", headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ chat_id: chatId, text, disable_web_page_preview: false }),
  }).then(r => r.json()).catch(e => ({ ok: false, description: String(e) }));
  if (!r.ok) console.log("  전송 실패:", r.description);
  return r.ok;
};

const look = async () => {
  const r = await fetch(url, { headers: { "user-agent": UA } });
  const html = await r.text();
  // 태그를 걷어내고 본문 글자만 본다(화면에 보이는 것과 맞추기 위해)
  const text = html.replace(/<script[\s\S]*?<\/script>/gi, " ").replace(/<style[\s\S]*?<\/style>/gi, " ").replace(/<[^>]+>/g, " ");
  return text.includes(needle);
};

(async () => {
  let had;
  try { had = await look(); } catch (e) { console.log("주소를 못 여네요:", e.message); process.exit(1); }
  const goal = onAppear ? "생기면" : "사라지면";
  console.log(`[${now()}] 지켜봅니다 , "${needle}" 이(가) ${goal} 알림. ${mins}분 간격`);
  console.log(`  지금 상태: "${needle}" ${had ? "있음" : "없음"}`);
  await tg(`지켜보기 시작했습니다.\n"${needle}" 이(가) ${goal} 알려드릴게요.\n${url}`);

  for (;;) {
    await new Promise(s => setTimeout(s, mins * 60000));
    let cur;
    try { cur = await look(); } catch (e) { console.log(`[${now()}] 못 읽음(${e.message}) , 다음에 다시`); continue; }
    const hit = onAppear ? (!had && cur) : (had && !cur);
    console.log(`[${now()}] "${needle}" ${cur ? "있음" : "없음"}${hit ? "  ← 바뀌었습니다" : ""}`);
    if (hit) {
      await tg(`🔔 바뀌었습니다\n"${needle}" 이(가) ${onAppear ? "생겼어요" : "사라졌어요"}.\n${url}`);
      console.log("  폰으로 보냈습니다. 지켜보기를 마칩니다.");
      process.exit(0);
    }
    had = cur;
  }
})();
STEP 3

돌려보기

터미널에서 그 폴더로 들어가 순서대로 칩니다.

명령 , 준비 한 번 + 지켜보기
# 준비 (딱 한 번)
node setup.js 1234567890:AAH여기에내토큰을그대로

# '품절'이 사라지면 알림 (= 재입고)
node watch.js "https://지켜볼주소" "품절"

# '예약하기'가 생기면 알림 (= 오픈)
node watch.js "https://지켜볼주소" "예약하기" --있으면

# 확인 간격을 정하고 싶으면 뒤에 분을 붙입니다 (기본 5분)
node watch.js "https://지켜볼주소" "품절" 10

setup.js 를 돌렸을 때 폰에 테스트 메시지가 오면 성공입니다. 안 오면 아래 "막히는 곳"을 보세요.

찾을 말은 화면에 그대로 보이는 걸로 고르세요. "품절", "SOLD OUT", "재입고 알림" 처럼요. 상품 페이지에서 그 글자를 눈으로 확인하고 똑같이 넣으면 됩니다. 띄어쓰기까지 같아야 합니다.
RESULT

실제 실행 기록

지어낸 화면이 아니라 실행 로그 그대로입니다. 테스트 페이지의 "품절"을 "구매하기"로 바꿔놓고 1분 간격으로 지켜보게 했습니다.

터미널 출력 , 2026년 8월 19일
$ node watch.js "http://127.0.0.1:8901/live.html" "품절" 1
[확인] 지켜봅니다 , "품절" 이(가) 사라지면 알림. 1분 간격
  지금 상태: "품절" 있음
[확인] "품절" 없음  ← 바뀌었습니다
  폰으로 보냈습니다. 지켜보기를 마칩니다.

폰으로는 이렇게 옵니다.

텔레그램 메시지
🔔 바뀌었습니다
"품절" 이(가) 사라졌어요.
http://127.0.0.1:8901/live.html

바뀐 지 1분 만에 폰에 도착했습니다. 실제 쇼핑몰에 걸 때는 기본값인 5분이면 충분합니다.

TRAPS

막히는 곳 네 가지

⚠ 아직 대화가 없습니다

제일 흔합니다. 내 봇에게 먼저 말을 안 걸어서 그렇습니다. 텔레그램에서 봇 아이디를 검색해 "안녕" 한 마디 보내고 setup.js 를 다시 돌리세요.

⚠ 토큰이 틀렸습니다

복사할 때 앞뒤로 공백이나 줄바꿈이 붙은 경우가 많습니다. 따옴표 없이 그대로 붙여넣으세요. 그래도 안 되면 @BotFather 에서 /mybots → 봇 선택 → API Token 으로 다시 받으세요.

⚠ 알림이 안 옵니다 (에러는 없는데)

그 페이지가 자바스크립트로 나중에 그리는 화면일 수 있습니다. 이 도구는 서버가 처음 보내주는 HTML 만 봅니다. 확인법: 브라우저에서 그 페이지를 열고 Ctrl+U(소스 보기) 를 눌러 "품절"이 있는지 찾아보세요. 없으면 이 방법으로는 안 잡힙니다. 그럴 땐 브라우저를 직접 띄우는 방식(Playwright)이 필요합니다.

⚠ 페이지를 못 여네요

로그인이 필요한 곳이거나, 봇 접근을 막아둔 곳입니다. 로그인 없이 보이는 주소로 거세요. 상품 상세 페이지는 대개 로그인 없이 열립니다.

지킬 것 하나 , 간격을 1분 밑으로 내리지 마세요. 남의 서버를 계속 두드리는 일이라 IP 가 차단될 수 있습니다. 코드에도 1분 하한을 걸어뒀습니다. 재입고는 보통 몇 시간 단위로 열리니 5분이면 놓치지 않습니다.

여기서 더 나가면

이 코드는 "글자가 있냐 없냐"만 봅니다. 여기에 붙일 수 있는 것들입니다. 클로드에게 watch.js 를 보여주고 그대로 시키면 고쳐줍니다.

하고 싶은 것클로드에게 이렇게
주소 여러 개 한꺼번에"목록 파일을 읽어서 여러 주소를 동시에 지켜보게 해줘"
가격이 얼마 이하면 알림"글자 대신 가격 숫자를 뽑아서 12만원 밑으로 떨어지면 알려줘"
알린 뒤에도 계속 지켜보기"보내고 끝내지 말고 계속 지켜보되 같은 알림은 하루 한 번만 보내줘"
자바스크립트 페이지"Playwright 로 브라우저를 띄워서 화면에 보이는 글자로 판단하게 해줘"
컴퓨터 꺼도 돌게"이걸 클라우드플레어 워커 크론으로 옮겨줘"
이 다섯 개 다 30분 안에 됩니다. 원본이 60줄짜리라 클로드가 통째로 읽고 고칠 수 있습니다. 코드를 짧게 유지하는 게 나중에 고치기 쉬운 이유입니다.
