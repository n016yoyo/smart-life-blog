영상 뒤에 남은 답

제브(Jev)는 문장을 못 만듭니다. 텍스트와 "질문"을 주면 답만 돌려줘요: 이거냐 저거냐(choice), 몇 단계냐(score), 예냐 아니오냐(noul). 그 답에 확률이 붙어 나옵니다. 그래서 LLM 을 대신하는 게 아니라 LLM 앞에 세우는 문지기로 씁니다.

공식 문서(docs.typesafe.ai)는 한국어(CJK) 정확도가 낮다고 적어 두었습니다. 그래서 제 댓글로 먼저 쟀습니다.

호출 한 번

OpenRouter 키 하나면 웨이트리스트 없이 됩니다(채팅 API 가 아니라 /api/alpha/decisions).

curl
curl -X POST https://openrouter.ai/api/alpha/decisions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" -H "Content-Type: application/json" \
  -d '{
    "model": "typesafe/jev-1.13",
    "state": { "comment": "목소리가 별로예요 😮 성악가같애요" },
    "questions": {
      "intent": { "type": "choice", "instructions": "What does this Korean Instagram comment intend?",
        "criteria": { "link_request": "Wants the guide link", "praise": "Positive reaction", "negative_feedback": "Complaint", "question": "Asks a question", "spam": "Advertising", "other": "None" } },
      "needs_owner": { "type": "noul", "instructions": "The channel owner should personally read this" }
    }
  }'

응답: intent.choice = "negative_feedback" (0.99) · needs_owner.noul = 0.57 · 0.28초 · $0.00002

제 계정에 붙인 문지기

키워드 「클로드」 밖 댓글만 제브가 봅니다. 답글 문장은 전부 사람이 미리 쓴 것, 제브는 고르기만.

1

스팸이면 아무것도 안 함

맞팔·광고(스팸, 확신 0.7 이상)와 어느 답글에도 안 맞는 댓글(none, 또는 확률 0.35 미만)은 답글 없이 기록만.

2

나머지는 답글 뱅크에서 하나 고름

뱅크 24종(답글 문장 22: 칭찬·웃음·이모지·응원·다음편 요청·목소리/속도/오류 불만·가격/설치/비교/가능 질문·링크 변형·수식 장난·인사·부탁). 제브가 댓글을 읽고 제일 맞는 걸 확률과 함께 돌려주면 그 문장을 답니다. 확률 0.35 미만이면 안 답니다.

3

질문·불만은 저한테 알림

제브가 "주인이 직접 봐야 함" 을 0.5 이상으로 보면 텔레그램으로 옵니다. 그래서 놓치던 20%가 사라졌습니다.

제 결론

댓글 하루 수십 건 규모면 클로드만 써도 비용 차이는 몇십 원입니다. 제브의 값어치는 속도·확신 수치·스팸 선차단이에요. 문장을 지어내지 않는다는 점이 공개 답글엔 오히려 안전했습니다. 한국어는 짧은 댓글 6분류에선 다 맞았지만, 긴 글은 직접 재보세요(공식 권고).
