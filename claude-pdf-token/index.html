AI TIGER MASK

클로드에 PDF 올리면 한도가 두 배로 닳습니다

각 페이지를 이미지로도 변환해서 글자값과 그림값을 둘 다 냅니다. 공식 문서에 적힌 값으로 계산하면 한 페이지가 2,796~4,296 토큰, 거의 두 배. 무료 도구로 고치는 법과, 한글 문서에서 실제로 깨지는 부분까지 직접 돌려보고 적었습니다.

공식 문서 원문 인용 도구 무료·MIT 한글 실측 한계 읽는 데 5분
👀 지금까지 … 명이 봤어요
왜 두 배인가 공식 숫자 고치는 세 단계 직접 돌려본 결과 한글에서 깨지는 것 언제 안 바꿔도 되나 출처
WHY

왜 두 배인가

클로드에 PDF 를 올리면 안에서 이런 일이 일어납니다. 앤트로픽 공식 문서에 그대로 적혀 있습니다.

"The system converts each page of the document into an image.
The text from each page is extracted and provided alongside each page's image."
, 각 페이지를 이미지로 변환하고, 페이지에서 뽑은 글자를 그 이미지 옆에 같이 넣는다

핵심은 alongside 입니다. 글자 대신 이미지를 넣는 게 아니라 둘 다 넣습니다. 그래서 한 페이지가 두 번 세어집니다.

📄 페이지 → 글자 🖼️ 페이지 → 이미지 둘 다 내 한도에서
NUMBERS

공식 문서에 나온 숫자

항목공식 문서 표기
글자 값페이지당 1,500~3,000 토큰 (내용 밀도에 따라)
그림 값페이지가 이미지로 변환되므로 이미지 토큰 계산이 그대로 추가
이미지 토큰 계산식⌈가로/28⌉ × ⌈세로/28⌉ , 공식 표에 1000×1000 = 1,296 토큰
한 페이지 합계1,500~3,000 + 1,296 = 2,796~4,296 토큰
거의 두 배입니다. 그것도 아직 아무것도 물어보기 전입니다. 질문과 답변은 여기에 더해집니다.
⚠️ 흔히 도는 "7배"는 다른 이야기입니다

같은 문서 안에 "3페이지 PDF 가 1,000 대 7,000 토큰"이라는 대목이 있는데, 그건 Amazon Bedrock 의 Converse API 절에 있는 값입니다. 원문에 "Opus 4.6 이전 Bedrock Converse API 를 쓸 때"라는 한정이 붙어 있어요.

일반 사용에 그대로 적용하면 과장이 됩니다. 그래서 이 글은 플랫폼 한정이 없는 절의 값만 씁니다.

⚠️ 정직하게 밝힙니다

위 토큰 숫자는 공식 문서에 적힌 값이고, 저희가 직접 잰 것이 아닙니다. 토큰을 정확히 세려면 API 키가 필요한데 저희는 구독 로그인만 쓰고 있어서요.

대신 변환이 실제로 되는지, 무엇이 깨지는지는 직접 돌려서 확인했습니다(아래 두 절).

FIX

고치는 세 단계

1. MarkItDown 을 한 번만 깝니다

마이크로소프트가 만든 무료 도구입니다. PDF·워드·엑셀을 글자(마크다운)로 바꿔줍니다. MIT 라이선스, 깃허브 별 175,000개.

터미널 , 둘 중 하나
pip install "markitdown[pdf]"

# pip 이 없으면 uv 로
uv tool install "markitdown[pdf]"

2. PDF 말고 바뀐 글자 파일을 올립니다

터미널
markitdown 계약서.pdf > 계약서.md

나온 .md 파일을 클로드에 올리면 됩니다. 페이지 이미지가 아예 없으니 글자값만 나갑니다.

3. 그림이랑 표를 봐야 할 때만 원본을 씁니다

차트를 읽어달라거나 도면을 봐야 하면 PDF 그대로가 맞습니다. 그때는 이미지값이 필요해서 내는 돈입니다. 글자만 필요한데 내는 게 아까운 거예요.

클로드 데스크톱에 아예 붙여두려면

MCP 서버도 같이 나옵니다. 한 번 설정하면 파일을 넣을 때마다 자동으로 바뀝니다.

pip install markitdown-mcp 후 claude_desktop_config.json 에 등록합니다. 설정 예시는 깃허브 packages/markitdown-mcp 에 있습니다.

TEST

직접 돌려본 결과

15장짜리 영문 논문 PDF 로 시험했습니다.

결과
원본 PDF2.2 MB · 15페이지
변환한 마크다운40 KB
살아남은 본문831줄 , 제목·초록·본문 전부
본문은 통째로 살아남습니다. 읽고 요약하고 질문하는 용도라면 이걸로 충분합니다.
LIMIT

한글에서 깨지는 것

이 부분은 해외 소개 글에 잘 안 나옵니다. 실제 배포된 한글 보도자료 PDF 로 확인했습니다.

✅ 본문은 그대로

- 심사평가원 등의 보건의료 데이터로 뇌동맥류 발병위험 예측 알고리즘 개발 등

❌ 제목 줄은 표로 깨짐

| 공공기관 | | 데이터, | | 민간 | 개방을 | 통해 |
| 협업도 | 하고 | 새로운 | 서비스도 | 창출한다. |

비어있지 않은 61줄 중 17줄이 이렇게 깨졌습니다. 네 줄에 한 줄꼴이에요. 그리고 제목만 그런 게 아닙니다 , 17줄 중 제목은 2줄이고 나머지 15줄은 본문 문단이었습니다.

그래서 이렇게 씁니다. 읽고 요약하고 질문하는 용도라면 충분합니다. 다만 올리기 전에 바뀐 파일을 한 번 열어보세요. 인용을 그대로 옮겨야 하는 작업이면 더 그렇습니다.
⚠️ 시험 대상을 한 번 바꿨습니다

처음엔 저희가 브라우저로 만든 PDF 로 시험했는데 폰트 관련 경고가 100줄 넘게 나왔습니다. 그건 도구 문제가 아니라 저희가 만든 PDF 문제였습니다. 그래서 실제 배포된 PDF 로 바꿔 다시 쟀고, 그때는 경고가 하나도 없었습니다.

SKIP

언제는 안 바꿔도 되나

  • 차트·도면·사진을 읽어달라고 할 때 , 이미지값이 있어야 그걸 봅니다. 원본이 맞습니다
  • 한두 장짜리 짧은 문서 , 아껴지는 양이 작아서 손이 더 듭니다
  • 표 위치가 그대로여야 할 때 , 변환하면 표 모양이 달라질 수 있습니다
한 줄로. 글자만 필요한데 그림값까지 내고 있는 경우만 바꾸면 됩니다. 그게 대부분입니다.
