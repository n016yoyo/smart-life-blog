클라우드 세션 시작하기

데스크톱 앱에서 Local 대신 Cloud 를 고르거나, 웹(claude.ai/code)·폰 앱 Code 탭에서 저장소를 골라 시작해요. 터미널에서는 claude --cloud "할 일". 처음이면 깃허브 연결과 Claude GitHub App 설치가 필요해요.
