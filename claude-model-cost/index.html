가격표 구간 때문에 배수는 환경마다 달라질 수 있어요

아홉 번 중 프롬프트가 10만 토큰을 넘는 요청이 섞여 있어서(최대 약 15만), Haiku 는 단가가 더 비싼 구간($2.50)이 일부 적용됐을 수 있어요. 그래서 9.3배는 "이 실험 환경에서 CLI 가 계산한 값"이고, 프롬프트가 짧으면 배수가 더 커질 수 있습니다.

시간은 Haiku 가 제일 빠르지 않았어요

Sonnet(163초)이 Haiku(170초)보다 조금 빨랐습니다. Opus 와 비교하면 Haiku 가 약 1분 빨랐어요. 영상에서도 "Haiku 가 제일 빠르다"고는 말하지 않았습니다.

Haiku 는 더 많이 썼는데 왜 쌌을까요

Haiku 는 출력 토큰을 Opus 보다 56% 더 썼어요(43,387 대 27,765). 그런데도 쌌던 건 토큰 하나당 값이 훨씬 싸기 때문입니다(총 토큰은 세 모델이 비슷했고, 출력 토큰만 Haiku 가 많았어요). Anthropic 공식 가격표(출력 100만 토큰당): Opus 5.5 $20, Sonnet 5.5 $10, Haiku 5.5 $0.50(프롬프트 10만 토큰 이하 기준, 넘으면 $2.50). 아홉 번 중 Opus 와 Sonnet 의 여섯 번은 가격표로 계산한 비용이 보고된 값과 소수점 넷째 자리까지 같았어요. Haiku 는 요청마다 단가 구간이 섞여 있어 정확히 재현하지는 못했습니다(약 15% 차이).

직접 해 보세요

  1. /model 로 Haiku 5.5 를 고르고 아래 요청문을 보냅니다. 화면 아래에 s = 이번 세션만, Enter = 기본값으로 저장이라고 나와요. 비교만 할 거면 s 를 누르세요(Enter 를 누르면 다음 세션부터 계속 Haiku 가 기본이 됩니다).
  2. 새 대화에서 Opus 5.5 로 같은 요청문을 보냅니다.
  3. /usage 로 비교하세요. 구독이면 달러가 아니라 사용량 퍼센트가 나옵니다. API 계정이면 /cost 로 달러를 봅니다.
  4. 쉬운 일은 비싼 모델부터 시작하지 마세요. 내 작업으로 재 보고 정하세요.
