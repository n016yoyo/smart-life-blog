한 줄 요약

내 경우 보는 법

1

조언자 켜기

클로드 코드에서 /advisor 명령, 또는 설정에 "advisorModel": "opus". 이번 실험은 claude --model sonnet --settings '{"advisorModel":"opus"}' 로 돌렸습니다.

2

평소처럼 시키기

본체(Sonnet)가 일하다가 필요할 때 조언자(Opus)를 부릅니다. 이번엔 시작 직후 한 번, 파일을 쓴 뒤 한 번 불렀습니다.

3

끝나고 /cost

/cost 를 치면 Settings 의 Usage 탭이 열리고 Session 칸에 Total cost 와 모델별 줄이 나옵니다. claude-opus 줄의 input 과 cache read 를 보면 조언자가 얼마나 새로 읽었는지 보입니다.

알아 둘 것

구성마다 한 번씩 잰 값입니다. 같은 요청도 다시 시키면 숫자가 달라지고, 일의 종류가 바뀌면 조언자를 부르는 횟수도 달라집니다.

세 게임 모두 요청한 기능(트랙 한 바퀴, 컴퓨터 차 3대, 아이템 상자, 랩 타임·순위, 미니맵)을 넣었고 헤드리스 크로미움에서 오류 0 으로 돌았습니다. 어느 게임이 더 낫다는 순위는 매기지 않았습니다.
