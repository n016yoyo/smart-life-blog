한 줄 요약

클로드 코드에 모드라는 게 생겨서, 요청마다 5시간 한도가 몇 퍼센트포인트 움직였는지 스피너 옆에 보여주고 /ledger 로 요청별 한 줄을 보여주는 모드를 클로드한테 한 번 시켜 만들었습니다. 클로드가 일한 시간은 51초였고, 모드가 로드되려면 켜기 허가창에서 「Enable for this session」을 눌러야 했습니다.

요청 세 개를 한 번씩만 돌린 값입니다. 제 화면에서 5시간 한도는 1%씩만 움직였고(상태줄 10% → 11%), 달러는 구독이라 실제로 내는 돈이 아니라 클로드 코드가 계산한 값입니다.

요청마다 5시간 한도가 몇 퍼센트포인트 움직였는지 스피너 옆에 보여줘. /ledger 를 치면 요청마다 한 줄(프롬프트 앞 12자, 초, 달러, 한도 변화)을 40자 안에 보여주는 mod 로 만들어줘

한도 변화는 요청 시작과 끝의 5시간 한도(%) 차이고, 이 화면에서는 정수로만 움직였습니다. 그래서 더 싼 두 줄 질문에 +1 이 찍히고 테트리스에 +0 이 찍혔습니다. 달러는 요청 시작과 끝의 세션 누적 비용 차이입니다.

모드는 내 권한으로 도는 코드입니다. 파일을 읽어 보고, 폴더 안에서 claude plugin validate . | grep -o "calls:.*" | tr , "\n" 를 쳐서 이 모드가 클로드 코드에 시키는 일을 보세요. 이 모드가 시키는 호출은 네 개($.command.register, $.session.usage, $.state.get, $.state.set)였고 파일·네트워크 접근은 없었습니다. 보낸 요청의 앞 12자와 시간·비용·한도 변화는 그 세션 안에 저장합니다(파일로 쓰지 않습니다).

register.tsx · ledger/hooks/register.tsx
import { atom, read, update } from 'claude-code'
import type { Register } from 'claude-code'

import type { Live, Mark, Row } from '../types'
import { diff, five, line } from './format'

const mark = atom({ plugin: 'ledger', key: 'mark' } as const, null as Mark | null)
const live = atom({ plugin: 'ledger', key: 'live' } as const, { pct: null } as Live)
const rows = atom({ plugin: 'ledger', key: 'rows' } as const, [] as Row[])

export const register: Register = on => {
  on('session.start', async ($, e, next) => {
    await $.command.register({
      name: 'ledger',
      description: 'One line per request: prompt, seconds, dollars, 5h limit change',
    })

    return next(e)
  })

  on('prompt.submit', async ($, e, next) => {
    if (!e.text.startsWith('/')) {
      const u = await $.session.usage()
      const pct = five(u.rateLimits)
      await update($, live, () => ({ pct }))
      await update($, mark, () => ({
        prompt: e.text,
        startedAt: Date.now(),
        pct,
        usd: u.cost?.usd ?? 0,
      }))
    }

    return next(e)
  })

  on('session.measure', async ($, e, next) => {
    await update($, live, () => ({ pct: five(e.rateLimits) }))

    return next(e)
  })

  on('turn.complete', async ($, e, next) => {
    const m = await read($, mark)
    if (m) {
      const u = await $.session.usage()
      const row: Row = {
        prompt: m.prompt,
        seconds: Math.round((Date.now() - m.startedAt) / 1000),
        usd: Math.max(0, (u.cost?.usd ?? 0) - m.usd),
        delta: diff(five(u.rateLimits), m.pct),
      }
      await update($, rows, list => [...list, row].slice(-200))
      await update($, mark, () => null)
    }

    return next(e)
  })

  on('command.run', { command: 'ledger' }, async $ => {
    const list = await read($, rows)

    return { text: list.length ? list.slice(-30).map(line).join('\n') : 'No requests yet.' }
  })

  on('ui.render', { component: 'Spinner' }, async ($, e, next) => {
    const m = await read($, mark)
    const l = await read($, live)
    if (!m) return next(e)
    const d = diff(l.pct, m.pct)
    const tag = d === null ? '5h ?%p' : `5h ${d >= 0 ? '+' : ''}${d.toFixed(1)}%p`

    return next({ ...e, props: { ...e.props, suffix: `${e.props.suffix} ${tag}` } })
  })
}
format.ts · ledger/hooks/format.ts
import type { Row } from '../types'

export const MAX = 40

export const line = (r: Row): string => {
  const head = [...r.prompt.replace(/\s+/g, ' ').trim()].slice(0, 12).join('')
  const d = r.delta === null ? '?' : `${r.delta >= 0 ? '+' : ''}${r.delta.toFixed(1)}`
  return [...`${head} ${r.seconds}s $${r.usd.toFixed(2)} ${d}%p`].slice(0, MAX).join('')
}

export const five = (rl: readonly { kind: string; percentUsed: number }[]): number | null =>
  rl.find(w => w.kind === 'five_hour')?.percentUsed ?? null

export const diff = (now: number | null, then: number | null): number | null =>
  now === null || then === null ? null : Math.round((now - then) * 10) / 10

알아 둘 것

클로드가 짠 코드는 한 번 시킨 그대로입니다. 제가 고친 곳은 없고, 읽고 켰습니다. 사람이 짠 모드를 설치할 때도 같은 점검을 먼저 하세요.

이 모드는 요청이 끝나는 순간까지만 셉니다. 백그라운드 에이전트가 요청 뒤에도 도는 요청은 그 비용이 안 잡힐 수 있습니다(제가 확인하지 못한 부분입니다).

세 요청을 한 번씩만 돌렸습니다. 같은 요청을 반복해 폭을 재지 않았고, 달러가 요청 크기를 보여준다고도 말하지 않습니다(세션 첫 요청은 값이 크게 나왔을 수 있습니다).
