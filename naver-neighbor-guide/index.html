WHAT

이게 뭔데?

네이버 블로그를 키우려면 서로이웃 글에 들러 공감을 누르고 댓글을 답니다. 손으로 하면 한 곳당 1분, 이웃이 39곳이면 39분입니다. 매일이요.

그래서 자동화 도구를 찾으면 대부분 아무 글에나 같은 인사말을 붙이는 봇입니다. 받는 사람도 압니다. 그게 티가 나는 순간 이웃 관리가 아니라 스팸이 됩니다.

이 가이드가 만드는 것은 다릅니다. 크롬이 이웃 새글을 모으고 → 본문을 통째로 읽고 → 그 내용을 짚은 댓글을 Claude가 써서 → 공감과 함께 답니다. 글을 안 읽으면 나올 수 없는 문장이 나옵니다.
HONEST

먼저, 정직하게 짚고 갑니다

✓ 글 읽기·댓글 작성·공감 자동 △ 몇 곳을 돌지는 사람이 정함 △ 댓글 내용은 사람이 검토 권장

과장 없이 씁니다. 이건 사람 대신 읽고 쓰는 도구지, 계정을 방치해도 되는 도구가 아닙니다. 처음에는 --dry(댓글 생성만 하고 등록 안 함)로 몇 번 돌려 문장 품질을 눈으로 보고, 마음에 들 때 등록을 켜세요.

속도를 올리려고 병렬로 돌리지 마세요. 남의 블로그를 도는 자동화에서 방문 간격은 성능이 아니라 계정 안전장치입니다. 이 가이드는 방문마다 3~5초를 일부러 쉽니다.
PREP

준비물은 딱 하나

준비물설명
Claude Code이 도구를 만들어줄 주인공. 설치만 하면 됩니다. 설치 가이드
네이버 계정서로이웃이 맺어져 있는 계정. 부계정 권장
코딩 지식필요 없습니다. 아래 프롬프트를 그대로 붙여넣으면 됩니다.

따로 살 것도, 결제할 것도 없습니다.

STEP 1

네이버 로그인, 처음 한 번만

자동화가 매번 로그인을 물어보면 쓸모가 없습니다. 한 번 로그인한 상태를 파일로 저장해두고 계속 씁니다.

Claude Code에 그대로 붙여넣기
네이버에 로그인한 상태를 파일로 저장하는 스크립트를 만들어줘.

- Playwright로 크롬을 띄우고 headless는 끄기(내가 직접 로그인할 수 있게)
- 내가 로그인을 마칠 때까지 기다렸다가, 로그인 완료를 감지하면
  storageState를 naver_state.json 으로 저장
- 그 파일은 .gitignore 에 넣어서 절대 커밋되지 않게 해줘

★중요: 저장할 때 NID_AUT 와 NID_SES 쿠키가 실제로 들어있는지 먼저 확인하고,
없으면 파일을 덮어쓰지 말고 경고만 출력해줘.
왜 저 ★가 중요하냐면 , 네이버 로그인 쿠키는 만료값이 -1인 세션 쿠키라 브라우저를 닫으면 사라집니다. 이걸 모르고 종료 후에 저장하면 실행할 때마다 로그인이 지워집니다. 저는 이걸 모르고 한동안 로그아웃 상태로 돌렸습니다.
STEP 2

그다음부턴 명령 한 줄

Claude Code에 그대로 붙여넣기
네이버 서로이웃 순회 자동화를 만들어줘.

동작 순서
1) 저장해둔 naver_state.json 으로 로그인 상태를 복원하고
   https://section.blog.naver.com/BlogHome.naver 에서 이웃 새글 목록을 수집
2) 위에서부터 N개 글을 방문해서, 각 글의 본문 전체를 텍스트로 읽기
   (요약 말고 전문. .se-main-container 또는 #postViewArea)
3) 읽은 제목·본문을 Claude Code CLI(claude -p)에 넘겨 댓글 한 줄 생성
   규칙: 35자 이내 / 글에 실제로 나온 구체적 내용을 하나 짚을 것 /
        "잘 보고 가요" 같은 아무 글에나 붙는 인사 댓글 금지
4) 공감(하트) 누르고, 생성된 댓글 등록
5) 다음 글까지 3~5초 랜덤 대기

옵션
--dry      댓글을 생성만 하고 등록은 안 함(처음엔 이걸로 확인)
--nolike   공감도 누르지 않음
--rec      전 과정 화면 녹화

실행 결과(방문수·읽은 글자수·댓글·공감)를 JSON으로 저장해줘.

Claude가 코드를 다 짜면, 이후엔 이 한 줄입니다.

실행
node neighbor_round.js 3 --dry

TRAPS

실전 함정 5가지

직접 만들면서 실제로 막혔던 것들입니다. 미리 알면 몇 시간을 아낍니다.

1 · 댓글창이 DOM에 아예 없다

페이지를 열어도 댓글 입력창을 못 찾습니다. 네이버는 PostView iframe 안의 a.btn_comment를 눌러야 댓글 영역을 로드합니다. 그 전에는 존재하지 않습니다.

2 · click이 타임아웃난다

입력창을 찾아도 click()이 8초 타임아웃으로 실패합니다. 다른 요소에 가려져 있기 때문입니다. focus() 후 fill()이 훨씬 견고합니다.

3 · 실행할수록 로그인이 지워진다

위에서 말한 세션 쿠키 함정입니다. 저장 전에 NID_AUT·NID_SES가 있는지 확인하고, 없으면 덮어쓰지 않게 막아야 합니다.

4 · 본문을 "요약"해서 읽으면 티가 난다

본문 앞 몇 줄만 넘기면 댓글이 뻔해집니다. 전문을 넘겨야 구체적인 장면·수치를 짚습니다. 실제로 1,154자부터 3,257자까지 통째로 넘겼습니다.

5 · 공감을 두 번 누르면 취소된다

하트는 토글입니다. 이미 공감한 글에 또 누르면 취소됩니다. 누르기 전에 버튼 class에 on이 있는지 확인하세요.

SAFE

안전하게 오래 쓰는 법

  • 부계정으로 시작하세요. 자동화는 본인 계정 책임입니다.
  • 하루 방문 수를 적당히. 한 번에 수십 곳을 도는 것보다 매일 몇 곳이 안전합니다.
  • 대기 시간을 줄이지 마세요. 3~5초 간격은 느린 게 아니라 안전장치입니다.
  • 처음엔 --dry로. 댓글 문장이 마음에 들 때까지 등록은 끄고 확인하세요.
  • 가끔 눈으로 확인하세요. 내가 단 댓글이 실제로 어떻게 보이는지 직접 보는 게 제일 확실합니다.
이웃 관리는 결국 관계입니다. 이 도구는 시간을 아껴줄 뿐, 성의를 대신하지는 않습니다. 그래서 "글을 읽고 쓴다"는 조건을 절대 빼지 않았습니다.
